# Skeleton

O Skeleton ocupa o lugar do conteúdo enquanto ele carrega. A forma segue o layout final, então a página não salta quando os dados chegam e a espera parece mais curta.

Use no lugar de um spinner quando o formato do que vai aparecer já é conhecido: uma linha de texto, um avatar, uma capa, um item de lista. Não use quando não há dados para mostrar — isso é Empty State — nem para um erro.

# Skeleton

The Skeleton takes the place of content while it loads. The shape follows the final layout, so the page does not jump when the data arrives and the wait feels shorter.

Use it in place of a spinner when the shape of what will appear is already known: a line of text, an avatar, a cover, a list item. Do not use it when there is no data to show — that is Empty State — nor for an error.

Each bone is decorative. The region that will be replaced announces the loading (`role="status"`, `aria-busy="true"` and an `aria-label`). Pass `label` only when a single Skeleton represents that region on its own.

</Lang>

## Text

Use for paragraphs, headings and metadata. The height follows the context font size (`1em`); the default width fills the line. Shorten the last lines with `width` to suggest real text.

## Circle

## Circle

Use in place of an avatar or any round brand mark. Without a measurement, the circle is 40px, the same size as the large avatar. If only one side is provided, the other follows and the circle stays square.

<Lang lang="pt-BR">
## Acessibilidade

- Sem `label`, o componente sai da árvore de acessibilidade (`aria-hidden="true"`). Vários ossos dentro de um layout não são lidos um a um.
- Com `label`, ele vira `role="status"` e o nome acessível é lido uma vez.
- A região que será trocada pelo conteúdo real deve ter `aria-busy="true"` enquanto os Skeletons estão visíveis, e perder o atributo quando o conteúdo entrar.
- Com `prefers-reduced-motion: reduce`, o brilho para e resta só a forma estática.
- Em `forced-colors`, a forma ganha um contorno do sistema para continuar visível.
</Lang>

<Lang lang="en-US">
## Accessibility

- Without `label`, the component leaves the accessibility tree (`aria-hidden="true"`). Several bones inside a layout are not read one by one.
- With `label`, it becomes `role="status"` and the accessible name is read once.
- The region that will be replaced by the real content must have `aria-busy="true"` while the Skeletons are visible, and lose the attribute when the content enters.
- With `prefers-reduced-motion: reduce`, the shimmer stops and only the static shape remains.
- In `forced-colors`, the shape gains a system outline to stay visible.
</Lang>

## Uso

### Web Component

```html
<lui-skeleton></lui-skeleton>
<lui-skeleton width="64%"></lui-skeleton>
<lui-skeleton shape="circle"></lui-skeleton>
<lui-skeleton shape="rectangle" height="10rem"></lui-skeleton>

<div role="status" aria-busy="true" aria-label="Carregando perfil">
  <lui-skeleton shape="circle"></lui-skeleton>
  <lui-skeleton width="48%"></lui-skeleton>
</div>
```

```html
<span class="skeleton"></span>
<span class="skeleton" style="--lui-skeleton-width: 64%"></span>
<span class="skeleton skeleton--circle"></span>
<span class="skeleton skeleton--rectangle"></span>
```
