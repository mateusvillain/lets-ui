# Date Picker

O Date Picker seleciona uma data num calendário. Com `range`, seleciona um
intervalo. Use quando a data é próxima ou quando o dia da semana importa, como
em agendamentos, reservas e prazos. Para datas distantes que a pessoa já sabe,
como a data de nascimento, um Input com máscara é mais rápido de preencher.

O campo tem a mesma anatomia, os mesmos estados e os mesmos tamanhos do Input.
O valor é uma string ISO 8601 em qualquer idioma: `YYYY-MM-DD` para uma data e
`YYYY-MM-DD/YYYY-MM-DD` para um intervalo.

## Range

Use `range` para escolher um período, como uma hospedagem, férias ou o filtro
de um relatório. O calendário mostra dois meses lado a lado, então um intervalo
que passa de um mês para o outro aparece inteiro. O primeiro clique marca uma
ponta e o segundo marca a outra, em qualquer ordem. Entre os dois cliques, o
intervalo acompanha o ponteiro ou o foco do teclado. `Esc` cancela a seleção
incompleta e mantém o valor anterior.

O campo mostra as duas pontas com `Intl.DateTimeFormat.formatRange`, que não
repete o que elas têm em comum: `Jan 16 – 21, 2026`.

## Min e max

Use `min` e `max` para limitar as datas que podem ser escolhidas. Por exemplo,
uma reserva que não pode ser no passado ou um prazo que não pode passar do fim

## Idioma e início da semana

`locale` recebe uma tag BCP 47 e define o idioma do mês no cabeçalho, dos dias
da semana, dos nomes acessíveis dos dias e do texto do campo. O texto do campo
segue a convenção de cada idioma. A ordem de dia, mês e ano, a abreviação do mês
e a pontuação mudam conforme a `locale`:

| `locale` | Data               | Range                   |
| -------- | ------------------ | ----------------------- |
| `en-US`  | Oct 16, 2026       | Oct 16 – 21, 2026       |
| `en-GB`  | 16 Oct 2026        | 16 – 21 Oct 2026        |
| `pt-BR`  | 16 de out. de 2026 | 16 – 21 de out. de 2026 |
| `de-DE`  | 16. Okt. 2026      | 16.–21. Okt. 2026       |

Em todos os idiomas, o dia e o ano aparecem em números e o mês aparece
abreviado. O mês escrito evita confusão: `10/11/2026` é outubro nos Estados
Unidos e novembro no Brasil. A `locale` não altera o `value`, que fica em
ISO 8601.

Se o navegador não reconhecer a tag, o campo usa o idioma do navegador.

`first-day-of-week` define a primeira coluna do calendário. Nos Estados Unidos
e no Brasil a semana começa no domingo, e na maior parte da Europa começa na
segunda.

## Integração com formulários

O `lui-date-picker` é um form-associated custom element. O valor entra no
`FormData` do form com o `name` do campo, em ISO 8601.

A validação usa `ElementInternals.setValidity()`, como nos elementos nativos.
Com `required` e sem data, o campo reporta `valueMissing`. Um `value` que começa
antes de `min` reporta `rangeUnderflow`, e um que termina depois de `max`
reporta `rangeOverflow`. A mensagem exibida vem de `error-text`.

## Eventos

| Evento   | `detail`                                        | Quando                                    |
| -------- | ----------------------------------------------- | ----------------------------------------- |
| `change` | `{ value: string }`                             | O usuário escolhe uma data                |
| `change` | `{ value: string, start: string, end: string }` | Com `range`, o usuário fecha um intervalo |

## Atributos

| Atributo            | Tipo      | Padrão    | Descrição                                                                |
| ------------------- | --------- | --------- | ------------------------------------------------------------------------ |
| `value`             | `string`  | `''`      | Data selecionada em `YYYY-MM-DD`, ou `YYYY-MM-DD/YYYY-MM-DD` com `range` |
| `range`             | `boolean` | `false`   | Seleciona um intervalo, com dois meses lado a lado                       |
| `min`               | `string`  | `''`      | Primeira data selecionável, `YYYY-MM-DD`                                 |
| `max`               | `string`  | `''`      | Última data selecionável, `YYYY-MM-DD`                                   |
| `open`              | `boolean` | `false`   | Calendário aberto, refletido como atributo                               |
| `locale`            | `string`  | `'en-US'` | Idioma de exibição (tag BCP 47), via `Intl.DateTimeFormat`               |
| `first-day-of-week` | `number`  | `0`       | Primeira coluna do calendário: `0` domingo … `6` sábado                  |
| `size`              | `string`  | `'lg'`    | `lg` ou `md`                                                             |
| `label`             | `string`  | `''`      | Rótulo do campo                                                          |
| `hint`              | `string`  | `''`      | Texto de apoio abaixo do campo                                           |
| `error`             | `boolean` | `false`   | Exibe o estado de erro e a mensagem de `error-text`                      |
| `disabled`          | `boolean` | `false`   | Desabilita o campo                                                       |
| `optional`          | `boolean` | `false`   | Exibe o marcador de `optional-text` ao lado do rótulo                    |
| `name`              | `string`  | `''`      | Nome do campo no `FormData`                                              |
| `required`          | `boolean` | `false`   | Bloqueia a submissão sem data                                            |

## Textos padrão

Os textos gerados pelo componente estão em inglês. Troque-os pelos atributos
abaixo para usar o idioma do projeto.

| Atributo               | Padrão                      | Descrição                                     |
| ---------------------- | --------------------------- | --------------------------------------------- |
| `placeholder`          | `'Select a date'`           | Texto do campo sem data                       |
| `optional-text`        | `'(optional)'`              | Marcador exibido quando `optional` está ativo |
| `error-text`           | `'This field is required.'` | Mensagem exibida quando `error` está ativo    |
| `dialog-label`         | `'Choose date'`             | Nome acessível do calendário                  |
| `previous-month-label` | `'Previous month'`          | `aria-label` do botão de mês anterior         |
| `next-month-label`     | `'Next month'`              | `aria-label` do botão de próximo mês          |

## Acessibilidade

O campo é um `<button aria-haspopup="dialog">` nomeado pelo rótulo e pela data
exibida. O calendário segue o padrão
[Date Picker Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/datepicker-dialog/)
do WAI-ARIA APG. Os dias ficam numa `grid` com um único ponto de tabulação, o
mês é anunciado numa região `aria-live` e o dia de hoje tem
`aria-current="date"`.

| Tecla                        | Ação                                           |
| ---------------------------- | ---------------------------------------------- |
| `Enter`, `Space`, `↓`        | No campo, abre o calendário no dia selecionado |
| `←` `→`                      | Dia anterior / seguinte                        |
| `↑` `↓`                      | Mesma coluna na semana anterior / seguinte     |
| `Home` `End`                 | Início / fim da semana                         |
| `Page Up` `Page Down`        | Mês anterior / seguinte                        |
| `Shift` + `Page Up` / `Down` | Ano anterior / seguinte                        |
| `Enter`, `Space`             | Seleciona o dia focado e fecha                 |
| `Esc`                        | Fecha sem alterar e devolve o foco ao campo    |

O calendário também fecha com um clique fora dele ou quando o foco sai com `Tab`.

## Uso

```html
<lui-date-picker
  name="check-in"
  label="Check-in"
  min="2026-01-12"
  max="2026-01-28"
></lui-date-picker>

<script>
  document
    .querySelector('lui-date-picker')
    .addEventListener('change', (e) => console.log(e.detail.value));
</script>
```
