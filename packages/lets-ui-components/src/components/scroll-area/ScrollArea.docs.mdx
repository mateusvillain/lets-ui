# ScrollArea

Uma região rolável acessível por teclado que abstrai o comportamento de overflow, os indicadores visuais de overflow, o scroll snap e os eventos de rolagem numa API consistente e independente de framework.

<Lang lang="en-US">
# ScrollArea

A keyboard-accessible scrollable region that abstracts overflow behavior, visual overflow indicators, scroll snap, and scroll events into a consistent, framework-agnostic API.

The component wraps content in a Shadow DOM viewport div. Overflow, snap, and dimensions are applied as inline styles by JavaScript; visual indicators update automatically as the user scrolls.

## scrollbar-visibility

Controla quando a barra de rolagem fica visível.

| Valor    | Comportamento                                              |
| -------- | ---------------------------------------------------------- |
| `auto`   | Padrão do navegador — aparece quando o conteúdo transborda |
| `always` | Barra de rolagem sempre renderizada (`overflow: scroll`)   |
| `hover`  | Oculta em repouso, visível quando a área está em hover     |
| `hidden` | Nunca exibida, mas o conteúdo continua rolável             |

</Lang>

## fade

Renderiza sobreposições em gradiente para indicar conteúdo oculto. Ativa e desativa automaticamente conforme o usuário rola.

Use como booleano para habilitar o fade em todos os lados relevantes para a `orientation`:

```html
<lui-scroll-area fade>…</lui-scroll-area>
```

Ou especifique de quais lados deve haver fade:

```html
<lui-scroll-area fade="top bottom">…</lui-scroll-area>
<lui-scroll-area fade="bottom">…</lui-scroll-area>
```

O gradiente vai da cor de fundo da superfície (token `bg(surface, neutral)`) ao transparente. Substitua com a propriedade customizada de CSS `--lui-scroll-area-fade-color` ao colocar o componente em outro fundo:

```css
lui-scroll-area {
  --lui-scroll-area-fade-color: var(--my-card-background);
}
```

</Lang>

<Lang lang="en-US">
## fade

Renders gradient overlays to indicate hidden content. Activates and deactivates automatically as the user scrolls.

Use as a boolean to enable fade on all sides relevant to the `orientation`:

```html
<lui-scroll-area fade>…</lui-scroll-area>
```

Or specify which sides should fade:

```html
<lui-scroll-area fade="top bottom">…</lui-scroll-area>
<lui-scroll-area fade="bottom">…</lui-scroll-area>
```

The gradient blends from the surface background color (token `bg(surface, neutral)`) to transparent. Override it with the `--lui-scroll-area-fade-color` CSS custom property when placing the component on a different background:

```css
lui-scroll-area {
  --lui-scroll-area-fade-color: var(--my-card-background);
}
```

Habilita o CSS Scroll Snap usando o `scroll-snap-type` nativo. Os filhos recebem automaticamente `scroll-snap-align` de acordo com o atributo `snap-align`.

## Eventos

O componente emite Eventos Customizados no elemento host. Todos os eventos borbulham e são compostos (atravessam os limites do Shadow DOM).

| Evento         | Quando                                      | `detail` payload                                                                  |
| -------------- | ------------------------------------------- | --------------------------------------------------------------------------------- |
| `scroll`       | A cada tick de rolagem                      | `{ scrollTop, scrollLeft, scrollHeight, scrollWidth, clientHeight, clientWidth }` |
| `scroll-start` | Primeiro tick de um novo gesto de rolagem   | —                                                                                 |
| `scroll-end`   | 150 ms após o último tick de rolagem        | —                                                                                 |
| `reach-top`    | A posição de rolagem chega à borda superior | —                                                                                 |
| `reach-bottom` | A posição de rolagem chega à borda inferior | —                                                                                 |
| `reach-left`   | A posição de rolagem chega à borda esquerda | —                                                                                 |
| `reach-right`  | A posição de rolagem chega à borda direita  | —                                                                                 |

```js
const area = document.querySelector('lui-scroll-area');

area.addEventListener('reach-bottom', () => {
  loadMoreItems();
});

area.addEventListener('scroll-end', () => {
  saveScrollPosition(area);
});
```

</Lang>

## Events

The component emits Custom Events on the host element. All events bubble and are composed (they cross Shadow DOM boundaries).

| Event          | When                                    | `detail` payload                                                                  |
| -------------- | --------------------------------------- | --------------------------------------------------------------------------------- |
| `scroll`       | Every scroll tick                       | `{ scrollTop, scrollLeft, scrollHeight, scrollWidth, clientHeight, clientWidth }` |
| `scroll-start` | First tick of a new scroll gesture      | —                                                                                 |
| `scroll-end`   | 150 ms after the last scroll tick       | —                                                                                 |
| `reach-top`    | Scroll position reaches the top edge    | —                                                                                 |
| `reach-bottom` | Scroll position reaches the bottom edge | —                                                                                 |
| `reach-left`   | Scroll position reaches the left edge   | —                                                                                 |
| `reach-right`  | Scroll position reaches the right edge  | —                                                                                 |

```js
const area = document.querySelector('lui-scroll-area');

area.addEventListener('reach-bottom', () => {
  loadMoreItems();
});

area.addEventListener('scroll-end', () => {
  saveScrollPosition(area);
});
```
