# Image

O componente `<lui-image>` envolve um `<img>` nativo (ou `<picture>`) com carregamento lazy, um shimmer de skeleton durante o carregamento, um fallback de erro e controles opcionais de proporção de aspecto / ajuste do objeto — evitando deslocamento de layout e melhorando a performance percebida.

## Uso

### Web Component

```html
<lui-image
  src="..."
  alt="Descrição"
  width="400px"
  aspect-ratio="16 / 9"
  radius="md"
  fit="cover"
></lui-image>
```

### Classe CSS

```html
<div
  class="img"
  style="width: 400px; aspect-ratio: 16 / 9; border-radius: 8px;"
>
  <img class="img__element" src="..." alt="Descrição" />
</div>
```

</Lang>
