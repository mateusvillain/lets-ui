# Box

Generic container with padding, background, border, and overflow control. Props that accept design tokens resolve to CSS custom properties automatically — including theme (`data-theme`) and brand (`data-brand`) switching.

## border-radius

Aceita o nome de uma escala de token ou qualquer valor CSS bruto.

| Valor    | Token                        | Resolvido           |
| -------- | ---------------------------- | ------------------- |
| `none`   | `--lui-border-radius-none`   | `0`                 |
| `xs`     | `--lui-border-radius-xs`     | definido pela marca |
| `sm`     | `--lui-border-radius-sm`     | definido pela marca |
| `md`     | `--lui-border-radius-md`     | definido pela marca |
| `lg`     | `--lui-border-radius-lg`     | definido pela marca |
| `xl`     | `--lui-border-radius-xl`     | definido pela marca |
| `circle` | `--lui-border-radius-circle` | `1000000px`         |

```html

<lui-box border-radius="circle">…</lui-box>
```

Aceita o nome de uma escala de token. `padding-x` e `padding-y` sobrescrevem horizontal e vertical independentemente.

| Valor | Token                    |
| ----- | ------------------------ |
| `xs`  | `--lui-spacing-fluid-4`  |
| `sm`  | `--lui-spacing-fluid-8`  |
| `md`  | `--lui-spacing-fluid-16` |
| `lg`  | `--lui-spacing-fluid-24` |
| `xl`  | `--lui-spacing-fluid-32` |
| `2xl` | `--lui-spacing-fluid-48` |

```html
<lui-box padding="md">…</lui-box>
<lui-box padding-x="xl" padding-y="sm">…</lui-box>
```

## Raw CSS fallback

Valores desconhecidos passam como estão, então valores CSS brutos e referências `var()` continuam funcionando.

```html
<lui-box background="#fef9c3" border-radius="12px" border-width="2px"
  >…</lui-box
>
<lui-box background="var(--lui-color-neutral-background-surface)">…</lui-box>
```

</Lang>

<Lang lang="en-US">

## Raw CSS fallback

Unknown values are passed through as-is, so raw CSS values and `var()` references continue to work.

```html
<lui-box background="#fef9c3" border-radius="12px" border-width="2px"
  >…</lui-box
>
<lui-box background="var(--lui-color-neutral-background-surface)">…</lui-box>
```

## Uso

### Web Component

```html
<lui-box
  padding="md"
  background="neutral/surface"
  border-radius="md"
  border-width="1"
  border-color="neutral/subtle"
>
  Conteúdo com padding interno
</lui-box>
```

### Classe CSS

```html
<div class="box box--padding-md">Conteúdo com padding interno</div>
```
