<Lang lang="pt-BR">
## Integração com formulários

### Required

`required` no grupo bloqueia a submissão enquanto nenhuma opção estiver selecionada. O evento `invalid` dispara no grupo e a mensagem de `error-text` é exibida abaixo das opções, representando o grupo como um todo.

</Lang>

<Lang lang="en-US">
## Form integration

### Required

`required` on the group blocks submission while no option is selected. The `invalid` event fires on the group and the `error-text` message is displayed below the options, representing the group as a whole.

</Lang>

<Canvas of={RadioGroupStories.Required} />

<Lang lang="pt-BR">
### Form Integration

O valor selecionado é submetido no `FormData` com a chave `name` do grupo. Múltiplos grupos independentes coexistem no mesmo form sem interferência.

</Lang>

<Lang lang="en-US">
### Form Integration

The selected value is submitted in `FormData` under the group `name` key. Multiple independent groups coexist in the same form without interference.

</Lang>

<Lang lang="pt-BR">
## Atributos

| Atributo     | Tipo           | Padrão                | Descrição                                                                     |
| ------------ | -------------- | --------------------- | ----------------------------------------------------------------------------- |
| `name`       | `string`       | `''`                  | Chave do campo no `FormData`                                                  |
| `label`      | `string`       | `''`                  | Texto exibido como `<legend>` do grupo                                        |
| `size`       | `'lg' \| 'md'` | `'lg'`                | Tamanho da label: `lg` → `body--lg`, `md` → `body--md`                        |
| `hint`       | `string`       | `''`                  | Texto auxiliar abaixo das opções; substituído por `error-text` quando há erro |
| `required`   | `boolean`      | `false`               | Bloqueia a submissão quando nenhuma opção está selecionada                    |
| `disabled`   | `boolean`      | `false`               | Desabilita todos os radios filhos e exclui o campo da submissão               |
| `error`      | `boolean`      | `false`               | Ativa o estado de erro manualmente                                            |
| `error-text` | `string`       | `'Select an option.'` | Mensagem exibida abaixo do grupo quando `error` é verdadeiro                  |
| `form`       | `string`       | `''`                  | ID do `<form>` associado; permite usar o grupo fora do `<form>`               |

</Lang>

<Lang lang="en-US">
## Attributes

| Attribute    | Type           | Default               | Description                                                                    |
| ------------ | -------------- | --------------------- | ------------------------------------------------------------------------------ |
| `name`       | `string`       | `''`                  | Field key in `FormData`                                                        |
| `label`      | `string`       | `''`                  | Text displayed as the group `<legend>`                                         |
| `size`       | `'lg' \| 'md'` | `'lg'`                | Label size: `lg` → `body--lg`, `md` → `body--md`                               |
| `hint`       | `string`       | `''`                  | Helper text below the options; replaced by `error-text` when there is an error |
| `required`   | `boolean`      | `false`               | Blocks submission when no option is selected                                   |
| `disabled`   | `boolean`      | `false`               | Disables all child radios and excludes the field from submission               |
| `error`      | `boolean`      | `false`               | Activates the error state manually                                             |
| `error-text` | `string`       | `'Select an option.'` | Message displayed below the group when `error` is true                         |
| `form`       | `string`       | `''`                  | ID of the associated `<form>`; lets you use the group outside the `<form>`     |

</Lang>

## Uso

### Web Component

```html
<lui-radio-group name="plano" label="Plano" size="lg">
  <lui-radio value="basic" label="Básico"></lui-radio>
  <lui-radio value="pro" label="Pro"></lui-radio>
</lui-radio-group>
```

### Classe CSS

```html
<fieldset class="radio-group radio-group--lg">
  <legend class="radio-group__legend">Plano</legend>
  <div class="radio-group__options">
    <label class="radio">
      <input type="radio" name="plano" value="basic" /> Básico
    </label>
    <label class="radio">
      <input type="radio" name="plano" value="pro" /> Pro
    </label>
  </div>
</fieldset>
```
