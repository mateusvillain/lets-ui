# Accordion

A list of collapsible sections. Each item has an actionable header that shows or hides the content panel, and the arrow next to the title rotates when the item opens. It works in one-open-at-a-time mode, which is the default, or with several open.

## Quando usar

Use o Accordion para revelar conteúdo relacionado, em seções que a pessoa pode querer ler uma de cada vez, como perguntas frequentes ou blocos de configuração.

- Não esconda informação essencial. Se quase todo mundo precisa ler o conteúdo, deixe-o visível ou comece com o item `open`.
- Escreva títulos que descrevam o conteúdo que será revelado. "Prazos de entrega" diz mais do que "Saiba mais", e o título é o nome que o leitor de tela anuncia.
- Quando só uma seção puder ficar aberta, mantenha o modo padrão. A regra é previsível: abrir um item fecha o que estava aberto.

</Lang>

<Lang lang="en-US">
## When to use

Use Accordion to reveal related content, in sections that a person may want to read one at a time, such as frequently asked questions or configuration blocks.

- Do not hide essential information. If almost everyone needs to read the content, keep it visible or start with the `open` item.
- Write titles that describe the content that will be revealed. "Delivery times" says more than "Learn more", and the title is the name the screen reader announces.
- When only one section can stay open, keep the default mode. The rule is predictable: opening an item closes the one that was open.

</Lang>

## Slots

O ícone à esquerda é o slot `icon`, e a área de descrição é o slot padrão do item. Os dois aceitam qualquer conteúdo. Sem ícone, o espaço dele some. Com ícone, a descrição se alinha à esquerda com o texto do título, e não com o ícone. Na classe CSS, adicione `accordion__item--with-icon` ao item.

## Slots

The icon on the left is the `icon` slot, and the description area is the item's default slot. Both accept any content. Without an icon, its space disappears. With an icon, the description aligns to the left with the title text, and not with the icon. In the CSS class, add `accordion__item--with-icon` to the item.

## Evento `lui-toggle`

Cada item emite `lui-toggle` com `{ open }` em `event.detail` quando abre ou fecha, seja por clique, porque outro item abriu ou por script. O evento borbulha e atravessa o shadow DOM. O estado inicial vindo do atributo `open` não emite o evento.

</Lang>

<Lang lang="en-US">
## Event `lui-toggle`

Each item emits `lui-toggle` with `{ open }` in `event.detail` when it opens or closes, whether by click, because another item opened or by script. The event bubbles and crosses the shadow DOM. The initial state coming from the `open` attribute does not emit the event.

</Lang>

## Acessibilidade

- Cada cabeçalho é um `<button>` dentro de um elemento com `role="heading"`. `Tab` e `Shift + Tab` percorrem os botões, e `Enter` ou `Espaço` abrem e fecham a seção.
- O botão expõe `aria-expanded` e `aria-controls`, que aponta para o painel.
- O painel não recebe `role="region"`: o padrão ARIA recomenda evitar o papel em accordions com muitos painéis, porque cada região vira um landmark e polui a navegação. A relação entre botão e painel fica por conta de `aria-controls`.
- Um painel fechado fica com `visibility: hidden`: o conteúdo não recebe foco nem é lido por leitor de tela.
- O foco visível usa o anel de foco do sistema, e o cabeçalho tem feedback de hover e de pressionado.
- A animação de altura e a rotação da seta são desligadas com `prefers-reduced-motion: reduce`.
- Item desabilitado recebe `disabled` e `aria-disabled="true"`.
- O ícone é decorativo: coloque `aria-hidden="true"` no SVG. A seta já é escondida do leitor de tela.
- `Seta para baixo` e `Seta para cima` movem o foco entre os cabeçalhos, voltando ao primeiro ou ao último nas pontas. `Home` e `End` vão para o primeiro e o último. Itens desabilitados são pulados, e as teclas só valem quando o foco está em um cabeçalho, não no conteúdo do painel.
- Essa navegação vem do Web Component. Na classe CSS, só `Tab` funciona.

</Lang>

<Lang lang="en-US">
## Accessibility

- Each header is a `<button>` inside an element with `role="heading"`. `Tab` and `Shift + Tab` move through the buttons, and `Enter` or `Space` open and close the section.
- The button exposes `aria-expanded` and `aria-controls`, which points to the panel.
- The panel does not receive `role="region"`: the ARIA pattern recommends avoiding the role in accordions with many panels, because each region becomes a landmark and clutters navigation. The relationship between button and panel is handled by `aria-controls`.
- A closed panel has `visibility: hidden`: the content is neither focusable nor read by screen readers.
- Visible focus uses the system focus ring, and the header has hover and pressed feedback.
- The height animation and the arrow rotation are turned off with `prefers-reduced-motion: reduce`.
- A disabled item receives `disabled` and `aria-disabled="true"`.
- The icon is decorative: put `aria-hidden="true"` on the SVG. The arrow is already hidden from the screen reader.
- `Arrow down` and `Arrow up` move focus between the headers, wrapping to the first or the last at the ends. `Home` and `End` go to the first and the last. Disabled items are skipped, and the keys only work when focus is on a header, not on the panel content.
- This navigation comes from the Web Component. In the CSS class, only `Tab` works.

</Lang>

## Uso

### Web Component

```html
<lui-accordion variant="bordered" heading-level="3">
  <lui-accordion-item label="Shipping" subtitle="Delivery times" open>
    <svg slot="icon" aria-hidden="true"><!-- ícone --></svg>
    Orders ship in two business days.
  </lui-accordion-item>
  <lui-accordion-item label="Returns">
    Returns are accepted within 30 days.
  </lui-accordion-item>
</lui-accordion>

<script>
  document
    .querySelector('lui-accordion')
    .addEventListener('lui-toggle', (event) => {
      console.log(event.target, event.detail.open);
    });
</script>
```

### Classe CSS

```html
<div class="accordion accordion--bordered">
  <div class="accordion__item accordion__item--open">
    <div class="accordion__heading" role="heading" aria-level="3">
      <button
        id="a1-trigger"
        class="accordion__trigger"
        type="button"
        aria-expanded="true"
        aria-controls="a1-panel"
      >
        <span class="accordion__text">
          <span class="accordion__title">Shipping</span>
        </span>
        <!-- svg.accordion__chevron -->
      </button>
    </div>
    <div id="a1-panel" class="accordion__panel">
      <div class="accordion__panel-inner">
        <div class="accordion__description">
          Orders ship in two business days.
        </div>
      </div>
    </div>
  </div>
</div>
```
