## Integração com formulários

O `lui-input` é um form-associated custom element — seus valores são capturados automaticamente
pelo `FormData` do form pai através do atributo `name`.

Use `form` para associar o input a um form por ID, mesmo que esteja fora do elemento `<form>` no DOM.

### Required

O atributo `required` bloqueia a submissão do form quando o campo está vazio.
A validação é implementada via `ElementInternals.setValidity()`, mantendo o comportamento
consistente com elementos nativos. A mensagem reportada é controlada pelo atributo `error-text`.

</Lang>

<Lang lang="en-US">

## Form integration

`lui-input` is a form-associated custom element — its values are captured automatically
by the parent form's `FormData` through the `name` attribute.

Use `form` to associate the input with a form by ID, even when it is outside the `<form>` element in the DOM.

### Required

The `required` attribute blocks the form submission when the field is empty.
Validation is implemented via `ElementInternals.setValidity()`, keeping the behavior
consistent with native elements. The reported message is controlled by the `error-text` attribute.

### Pattern

O atributo `pattern` aceita uma expressão regular para validar o valor final do campo,
via Constraint Validation API. Quando o valor não casa com o padrão, o campo reporta
`patternMismatch` através de `ElementInternals.setValidity()`, exibindo a mensagem de
`error-text`. Útil para indicar formato esperado de forma declarativa, como CEP ou
CPF/CNPJ sem máscara.

</Lang>

<Lang lang="en-US">

### Pattern

The `pattern` attribute accepts a regular expression to validate the final value of the field,
via the Constraint Validation API. When the value does not match the pattern, the field reports
`patternMismatch` through `ElementInternals.setValidity()`, showing the
`error-text` message. Useful to indicate the expected format declaratively, such as ZIP code or
CPF/CNPJ without a mask.

</Lang>

<Canvas of={InputStories.Pattern} />

<Lang lang="pt-BR">

### Input Mode

O atributo `inputmode` é refletido no `<input>` nativo e otimiza o teclado virtual
exibido em dispositivos touch para o tipo de dado esperado, sem alterar o tipo nativo
do campo (`type`). Aceita os valores padrão: `text`, `numeric`, `decimal`, `tel`,
`email`, `url`, `search` e `none`.

</Lang>

<Lang lang="en-US">

### Input Mode

The `inputmode` attribute is reflected on the native `<input>` and optimizes the virtual keyboard
shown on touch devices for the expected data type, without changing the field's native
type (`type`). It accepts the default values: `text`, `numeric`, `decimal`, `tel`,
`email`, `url`, `search` and `none`.

</Lang>

## Atributos de formulário

| Atributo    | Tipo      | Padrão  | Descrição                                                                                                             |
| ----------- | --------- | ------- | --------------------------------------------------------------------------------------------------------------------- |
| `name`      | `string`  | `''`    | Nome do campo nos dados submetidos; necessário para aparecer no `FormData`                                            |
| `form`      | `string`  | `''`    | ID do `<form>` associado; permite usar o input fora do elemento form                                                  |
| `required`  | `boolean` | `false` | Bloqueia a submissão quando o campo está vazio; valida via `ElementInternals`                                         |
| `pattern`   | `string`  | `''`    | Regex para validar o valor final; reporta `patternMismatch` via `ElementInternals`                                    |
| `inputmode` | `string`  | `''`    | Dica de teclado virtual em dispositivos touch (`text`, `numeric`, `decimal`, `tel`, `email`, `url`, `search`, `none`) |

</Lang>

<Lang lang="en-US">

## Form attributes

| Attribute   | Type      | Default | Description                                                                                                    |
| ----------- | --------- | ------- | -------------------------------------------------------------------------------------------------------------- |
| `name`      | `string`  | `''`    | Field name in the submitted data; required to appear in `FormData`                                             |
| `form`      | `string`  | `''`    | ID of the associated `<form>`; allows using the input outside the form element                                 |
| `required`  | `boolean` | `false` | Blocks submission when the field is empty; validates via `ElementInternals`                                    |
| `pattern`   | `string`  | `''`    | Regex to validate the final value; reports `patternMismatch` via `ElementInternals`                            |
| `inputmode` | `string`  | `''`    | Virtual keyboard hint on touch devices (`text`, `numeric`, `decimal`, `tel`, `email`, `url`, `search`, `none`) |

</Lang>

## Textos padrão

Os textos que o componente gera são em inglês e podem ser trocados por atributo, para seguir o idioma do projeto.

| Atributo              | Tipo     | Padrão                      | Descrição                                           |
| --------------------- | -------- | --------------------------- | --------------------------------------------------- |
| `optional-text`       | `string` | `'(optional)'`              | Marcador exibido quando `optional` está ativo       |
| `error-text`          | `string` | `'This field is required.'` | Mensagem exibida quando `error` está ativo          |
| `show-password-label` | `string` | `'Show password'`           | `aria-label` do botão que revela a senha            |
| `hide-password-label` | `string` | `'Hide password'`           | `aria-label` do botão que oculta a senha            |
| `increment-label`     | `string` | `'Increase value'`          | `aria-label` do botão de incremento (`type=number`) |
| `decrement-label`     | `string` | `'Decrease value'`          | `aria-label` do botão de decremento (`type=number`) |

</Lang>
