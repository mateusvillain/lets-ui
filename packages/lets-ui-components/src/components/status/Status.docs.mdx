## Quando usar

Use o Status para mostrar um estado que alguém confere de relance: o resultado de uma operação numa lista, a saúde de um serviço numa tabela, a disponibilidade de uma pessoa.

- Para uma mensagem que pede leitura ou ação, use o [Alert](?path=/docs/content-alert--docs). O Status só nomeia o estado.
- Para uma etiqueta que classifica um item, use a [Tag](?path=/docs/content-tag--docs).
- O Status não é interativo e não avisa quando muda. Se o estado muda na tela e a mudança precisa ser anunciada, coloque o Status dentro de uma região com `aria-live`.

</Lang>

<Lang lang="en-US">

## When to use

Use Status to show a state that someone checks at a glance: the result of an operation in a list, the health of a service in a table, a person's availability.

- For a message that asks for reading or action, use [Alert](?path=/docs/content-alert--docs). Status only names the state.
- For a tag that classifies an item, use [Tag](?path=/docs/content-tag--docs).
- Status is not interactive and does not announce when it changes. If the state changes on screen and the change needs to be announced, put Status inside a region with `aria-live`.

</Lang>

## Feedback

`success`, `caution`, `danger` e `info` usam as cores semânticas do sistema. Por padrão mostram um ícone de 20px. Com `dot`, mostram um ponto de 8px, mais discreto, bom para listas e tabelas com muitas linhas.

## Social

`online`, `away`, `busy` e `offline` são os status de presença de uma pessoa, os mesmos que o [Avatar](?path=/docs/content-avatar--docs) desenha no canto. O ponto mede 16px e tem uma forma própria além da cor, para que quem não distingue as cores ainda distinga os estados: `online` fica cheio, `away` mostra ponteiros de relógio, `busy` uma barra e `offline` um centro vazio.

## Social

`online`, `away`, `busy` and `offline` are a person's presence statuses, the same ones [Avatar](?path=/docs/content-avatar--docs) draws in the corner. The dot measures 16px and has its own shape beyond color, so that people who cannot distinguish colors can still distinguish the states: `online` is filled, `away` shows clock hands, `busy` a bar and `offline` an empty center.

## Rótulo e descrição

`label` é o texto do status e `description` uma segunda linha, em cor de legenda. O indicador fica centralizado nas letras maiúsculas da primeira linha do rótulo, e não no meio da caixa da linha: o texto não fica no centro da própria linha, e um indicador centralizado na caixa parece baixo demais.

</Lang>

<Lang lang="en-US">

## Label and description

`label` is the status text and `description` a second line, in caption color. The indicator is centered on the uppercase letters of the first line of the label, and not in the middle of the line box: the text is not centered in its own line, and an indicator centered on the box looks too low.

</Lang>

### Tamanhos

`size` muda só o tamanho do rótulo: `md` (padrão) ou `lg`. A descrição, o ícone e os pontos mantêm o tamanho. O indicador continua centralizado nas maiúsculas da primeira linha nos dois tamanhos, e também quando o rótulo quebra em mais de uma linha.

### Sizes

`size` changes only the label size: `md` (default) or `lg`. The description, the icon and the dots keep their size. The indicator stays centered on the uppercase letters of the first line in both sizes, and also when the label wraps to more than one line.

## Pulso

`pulse` faz um anel na cor do status crescer e sumir em volta do indicador. Use para um estado ao vivo: uma gravação, uma chamada, um serviço voltando. Com `prefers-reduced-motion: reduce`, o anel fica parado, como um halo, e a ênfase se mantém sem movimento.

</Lang>

<Lang lang="en-US">

## Pulse

`pulse` makes a ring in the status color grow and fade around the indicator. Use it for a live state: a recording, a call, a service coming back. With `prefers-reduced-motion: reduce`, the ring stays still, like a halo, and the emphasis is kept without motion.

</Lang>

## Classe CSS (sem Web Component)

Sem o Web Component, a marcação fica a cargo de quem usa. O indicador leva `aria-hidden="true"`. Os ícones de feedback não fazem parte da folha de estilo: sem o Web Component, use o ponto (`status__dot`), ou traga o seu SVG com a classe `status__icon`. Um status sem rótulo visível precisa de um `status__label status__label--hidden` com o texto.

</Lang>

<Lang lang="en-US">

## CSS class (without Web Component)

Without the Web Component, the markup is the responsibility of the consumer. The indicator carries `aria-hidden="true"`. The feedback icons are not part of the stylesheet: without the Web Component, use the dot (`status__dot`), or bring your own SVG with the `status__icon` class. A status without a visible label needs a `status__label status__label--hidden` with the text.

## Acessibilidade

- O Status não tem comportamento, então não entra na ordem de foco e não responde a teclado.
- O indicador (ícone ou ponto) leva `aria-hidden="true"`. O estado chega ao leitor de tela pelo texto: o `label`, ou o nome da variante quando não há `label`.
- O estado não depende só da cor: os ícones de feedback têm formas diferentes, e os pontos sociais têm uma forma dentro. Os pontos de feedback (`dot`) se distinguem só pela cor, então ponha o rótulo visível quando eles carregarem a informação.
- O Status não é `role="status"`. Esse papel é de uma região viva, que anuncia cada mudança, e um indicador estático numa tabela anunciaria ruído. Para anunciar uma mudança, envolva-o numa região com `aria-live="polite"`.
- Em modo de alto contraste (`forced-colors`), o indicador mantém as cores, porque a cor é a informação.
- O pulso respeita `prefers-reduced-motion`.

</Lang>

<Lang lang="en-US">

## Accessibility

- Status has no behavior, so it does not enter the focus order and does not respond to the keyboard.
- The indicator (icon or dot) carries `aria-hidden="true"`. The state reaches the screen reader through the text: the `label`, or the variant name when there is no `label`.
- The state does not depend on color alone: the feedback icons have different shapes, and the social dots have a shape inside. The feedback dots (`dot`) are distinguished only by color, so put the visible label when they carry the information.
- Status is not `role="status"`. That role belongs to a live region, which announces every change, and a static indicator in a table would announce noise. To announce a change, wrap it in a region with `aria-live="polite"`.
- In high contrast mode (`forced-colors`), the indicator keeps the colors, because color is the information.
- The pulse respects `prefers-reduced-motion`.

</Lang>

## Uso

### Web Component

```html
<lui-status variant="success" label="Pagamento aprovado"></lui-status>

<lui-status
  variant="danger"
  dot
  label="Sincronização falhou"
  description="Há 5 minutos"
></lui-status>

<lui-status variant="online" pulse label="Ao vivo"></lui-status>
```

### Classe CSS

```html
<span class="status status--success status--lg">
  <span class="status__indicator" aria-hidden="true">
    <span class="status__dot"></span>
  </span>
  <span class="status__text">
    <span class="status__label">Pagamento aprovado</span>
    <span class="status__description">Há 2 minutos</span>
  </span>
</span>
```
