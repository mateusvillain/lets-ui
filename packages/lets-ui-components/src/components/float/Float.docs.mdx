# Float

Absolutely positions a child element relative to its anchor. Use it to overlay badges, status dots, or any decorative element on top of another component — avatars, cards, icons.

The host element becomes an `inline-block` relative container, so no wrapper is needed.

# Float

Absolutely positions a child element relative to its anchor. Use it to overlay badges, status dots, or any decorative element on top of another component — avatars, cards, icons.

The host element becomes an `inline-block` relative container, so no wrapper is needed.

<Lang lang="pt-BR">
## All Placements

Nove posições pelo atributo `placement`: combinações de `top / middle / bottom` × `start / center / end`.

`start` e `end` seguem a direção do texto: numa página `dir="rtl"`, `top-end` fica no canto superior esquerdo. O `offset-x` acompanha, então um deslocamento positivo continua apontando para o fim da linha.

</Lang>

<Lang lang="en-US">
## All Placements

Nine positions from the `placement` attribute: combinations of `top / middle / bottom` × `start / center / end`.

`start` and `end` follow the text direction: on a `dir="rtl"` page, `top-end` sits on the top-left corner. `offset-x` follows along, so a positive shift still points to the end of the line.

</Lang>
