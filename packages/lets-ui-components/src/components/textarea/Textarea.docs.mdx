<Lang lang="pt-BR">
## Integração com formulários

O `lui-textarea` é form-associated — seu valor é capturado automaticamente pelo `FormData` do form pai através do atributo `name`. O atributo `form` permite associá-lo a um form por ID mesmo estando fora do elemento `<form>`.

### Required

Com `required`, o campo bloqueia a submissão quando está vazio via `ElementInternals.setValidity()`.

</Lang>

<Lang lang="en-US">
## Form integration

`lui-textarea` is form-associated — its value is automatically captured by the parent form `FormData` through the `name` attribute. The `form` attribute lets you associate it with a form by ID even when it is outside the `<form>` element.

### Required

With `required`, the field blocks submission when empty through `ElementInternals.setValidity()`.

</Lang>

<Lang lang="pt-BR">
## Atributos de formulário

| Atributo   | Tipo      | Padrão  | Descrição                                                                     |
| ---------- | --------- | ------- | ----------------------------------------------------------------------------- |
| `name`     | `string`  | `''`    | Nome do campo nos dados submetidos; necessário para aparecer no `FormData`    |
| `form`     | `string`  | `''`    | ID do `<form>` associado; permite usar o textarea fora do elemento form       |
| `required` | `boolean` | `false` | Bloqueia a submissão quando o campo está vazio; valida via `ElementInternals` |

</Lang>

<Lang lang="en-US">
## Form attributes

| Attribute  | Type      | Default | Description                                                                       |
| ---------- | --------- | ------- | --------------------------------------------------------------------------------- |
| `name`     | `string`  | `''`    | Field name in the submitted data; required to appear in `FormData`                |
| `form`     | `string`  | `''`    | ID of the associated `<form>`; lets you use the textarea outside the form element |
| `required` | `boolean` | `false` | Blocks submission when the field is empty; validates through `ElementInternals`   |

</Lang>
