# Icon Button

Botão compacto que exibe apenas um ícone, sem rótulo de texto. Use quando o espaço é limitado e a ação é reconhecível pelo ícone — como fechar, excluir ou navegar. Sempre forneça um `aria-label` descritivo para garantir acessibilidade.

## Tamanhos

O Icon Button está disponível em dois tamanhos: `lg` (40px) para áreas com mais espaço e `md` (32px) para layouts mais compactos como toolbars e tabelas.

## Disabled

Use o estado desabilitado quando a ação não está disponível no contexto atual. O botão fica visualmente inativo e não responde a interações.

## Estado de componentes acionados

Icon Buttons costumam abrir menus e painéis ou alternar formatações — como o botão de menu, o de
"mais opções" ou o de negrito numa toolbar. Informe o estado com `aria-expanded`, `aria-haspopup`
ou `aria-pressed` no próprio `<lui-icon-button>`. O componente repassa esses atributos ao `<button>`
interno, que é quem o leitor de tela anuncia; no elemento externo eles não teriam efeito.

Usado como `slot="trigger"` de um Modal ou Drawer, o botão recebe esses atributos do próprio
componente e anuncia "recolhido" ou "expandido" sem configuração adicional. O `aria-controls` que
eles definem não é repassado: um ID não pode ser referenciado através de shadow roots diferentes.

```html
<lui-icon-button
  aria-label="Mais opções"
  aria-expanded="false"
  aria-haspopup="menu"
>
  <svg aria-hidden="true" ...>...</svg>
</lui-icon-button>
<lui-icon-button aria-label="Negrito" aria-pressed="true">
  <svg aria-hidden="true" ...>...</svg>
</lui-icon-button>
```

## Uso

### Web Component

```html
<lui-icon-button size="lg" aria-label="Fechar">
  <svg width="24" height="24" ...>...</svg>
</lui-icon-button>
```

### Classe CSS

```html
<button class="icon-button icon-button--lg" aria-label="Fechar">
  <svg width="24" height="24" ...>...</svg>
</button>
```
