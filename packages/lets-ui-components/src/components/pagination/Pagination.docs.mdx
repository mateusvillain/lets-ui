# Pagination

Componente de navegação entre páginas de um conteúdo paginado. Renderiza os botões de página anterior e próxima e os números de página, destacando a página atual com `aria-current="page"`. # Pagination

Navigation component between pages of paginated content. Renders the previous and next page buttons and the page numbers, highlighting the current page with `aria-current="page"`. When there are more pages than fit in the visible range, gaps are replaced by an ellipsis (`…`), always keeping the first and the last page.

## Truncamento com reticências

A primeira e a última página ficam sempre visíveis; a página atual mantém `sibling-count` vizinhas de cada lado, e cada lacuna vira uma reticência. Depois de truncada, a lista tem sempre o mesmo número de itens, então a largura não muda durante a navegação.

## Truncation with ellipsis

The first and the last page are always visible; the current page keeps `sibling-count` neighbors on each side, and each gap becomes an ellipsis. After truncation, the list always has the same number of items, so the width does not change during navigation.

## Propriedades

| Atributo                | Tipo     | Padrão                      | Descrição                                                                                                         |
| ----------------------- | -------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `current-page`          | `number` | `1`                         | Página atual. Refletido no atributo ao navegar.                                                                   |
| `total-pages`           | `number` | `1`                         | Total de páginas.                                                                                                 |
| `sibling-count`         | `number` | `1`                         | Páginas vizinhas exibidas de cada lado da atual.                                                                  |
| `compact-sibling-count` | `number` | `0`                         | Vizinhas de cada lado abaixo de 768px (limitado a `sibling-count`). Primeira, última e atual permanecem visíveis. |
| `label`                 | `string` | `Pagination`                | Nome acessível do landmark `<nav>`.                                                                               |
| `previous-label`        | `string` | `Previous page`             | Nome acessível do botão de página anterior.                                                                       |
| `next-label`            | `string` | `Next page`                 | Nome acessível do botão de próxima página.                                                                        |
| `page-label`            | `string` | `Page`                      | Prefixo do nome acessível de cada página ("Page 3").                                                              |
| `status-label`          | `string` | `Page {current} of {total}` | Texto anunciado por leitores de tela após a troca de página.                                                      |

## Properties

| Attribute               | Type     | Default                     | Description                                                                                            |
| ----------------------- | -------- | --------------------------- | ------------------------------------------------------------------------------------------------------ |
| `current-page`          | `number` | `1`                         | Current page. Reflected in the attribute on navigation.                                                |
| `total-pages`           | `number` | `1`                         | Total number of pages.                                                                                 |

| `page-label`            | `string` | `Page`                      | Prefix of each page's accessible name ("Page 3").                                                      |
| `status-label`          | `string` | `Page {current} of {total}` | Text announced by screen readers after the page changes.                                               |

## Acessibilidade

- Renderizado como `<nav>` com uma lista (`<ul>`) de botões nativos: navegável com `Tab`, e `Enter` ou `Espaço` ativam a página.
- A página atual recebe `aria-current="page"`.
- O botão de página anterior fica desabilitado (`disabled` e `aria-disabled="true"`) na primeira página, e o de próxima página, na última.
- As reticências são decorativas (`aria-hidden="true"`).
- Depois de navegar, o foco permanece no controle usado; se ele ficar desabilitado ou deixar de existir, o foco vai para a página atual.

</Lang>

<Lang lang="en-US">

## Accessibility

- Rendered as a `<nav>` with a list (`<ul>`) of native buttons: reachable with `Tab`, and `Enter` or `Space` activate the page.
- The current page receives `aria-current="page"`.
- The previous page button is disabled (`disabled` and `aria-disabled="true"`) on the first page, and the next page button on the last.
- The ellipsis is decorative (`aria-hidden="true"`).
- After navigating, focus stays on the control used; if it becomes disabled or no longer exists, focus goes to the current page.

</Lang>

## Uso

### Web Component

```html
<lui-pagination current-page="1" total-pages="20"></lui-pagination>

<script>
  document
    .querySelector('lui-pagination')
    .addEventListener('lui-page-change', (event) => {
      console.log(event.detail.page);
    });
</script>
```

### Classe CSS

```html
<nav class="pagination" aria-label="Pagination">
  <ul class="pagination__list">
    <li>
      <a
        class="pagination__item pagination__item--direction"
        href="?page=1"
        aria-label="Previous page"
      >
        <!-- ícone -->
      </a>
    </li>
    <li><a class="pagination__item" href="?page=1">1</a></li>
    <li>
      <a class="pagination__item" href="?page=2" aria-current="page">2</a>
    </li>
    <li><a class="pagination__item" href="?page=3">3</a></li>
    <li>
      <a
        class="pagination__item pagination__item--direction"
        href="?page=3"
        aria-label="Next page"
      >
        <!-- ícone -->
      </a>
    </li>
  </ul>
</nav>
```
