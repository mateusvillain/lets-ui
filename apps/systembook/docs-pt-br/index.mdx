# Let's UI

Let's UI é um design system open source e agnóstico de framework, construído sobre design tokens, CSS e Web Components nativos, para criar interfaces consistentes e acessíveis em qualquer tecnologia.

## Por que Let's UI

- **Um sistema, várias marcas**: temas claro e escuro e várias marcas saem dos mesmos tokens, trocados com `data-theme` e `data-brand`, sem JavaScript.
- **Qualquer framework**: os Web Components são feitos com [Lit](https://lit.dev/) e funcionam em React, Vue, Angular, Svelte ou HTML puro.
- **Acessível desde o início**: todo componente é pensado para teclado, leitores de tela e contraste, com meta no nível AA da WCAG 2.2.
- **CSS primeiro**: primitivos de layout como Stack, Inline e Sidebar funcionam como classes CSS simples, sem nenhum JavaScript.

## Comece em minutos

Instale os estilos e os componentes:

```bash
npm install @lets-ui/styles @lets-ui/components
```

Importe os dois no ponto de entrada da aplicação:

```js
import '@lets-ui/styles';
import '@lets-ui/components';
```

E use os componentes no HTML:

```html
<lui-button variant="primary">Confirmar</lui-button>
```

Para testar sem instalar nada, pela CDN, ou para configurar temas e marcas, veja [Installation](get-started/developers/installation.mdx). Para React, Vue, Angular e renderização no servidor, veja [Frameworks](get-started/developers/frameworks.mdx).
