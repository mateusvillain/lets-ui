## flex

Shorthand to set up a flexbox container in a single line.

```scss
@include flex($direction, $align, $justify, $gap, $wrap)
```

| Parameter | Default | Values |
| --- | --- | --- |
| `$direction` | `row` | row \| row-reverse \| column \| column-reverse |
| `$align` | `center` | flex-start \| center \| flex-end \| stretch \| baseline |
| `$justify` | `flex-start` | flex-start \| center \| flex-end \| space-between \| space-around |
| `$gap` | `0` | any spacing value |
| `$wrap` | `nowrap` | nowrap \| wrap \| wrap-reverse |

```scss
@include flex(row, center, space-between, fluid(16));
```

## center

Centers the content with flexbox on the given axis.

```scss
@include center($axis)
```

| Parameter | Default | Values |
| --- | --- | --- |
| `$axis` | `both` | both \| x \| y |

```scss
// Center on both axes
@include center;

// Horizontally only
@include center(x);

// Vertically only
@include center(y);
```

## center-absolute

Absolutely centers an element relative to its parent with position: absolute.

```scss
@include center-absolute
```

```scss
.overlay__spinner {
  position: relative; // on the parent

  .spinner {
    @include center-absolute;
  }
}
```

## media-up

Applies styles from a minimum breakpoint up (mobile-first).

```scss
@include media-up($breakpoint)
```

| Parameter | Default | Values |
| --- | --- | --- |
| `$breakpoint` | `—` | sm \| md \| lg \| 1xl |

```scss
.sidebar {
  display: none;

  @include media-up(md) {
    display: block;
  }
}
```

## media-down

Applies styles below a maximum breakpoint.

```scss
@include media-down($breakpoint)
```

| Parameter | Default | Values |
| --- | --- | --- |
| `$breakpoint` | `—` | 1xs \| sm \| md \| lg \| 1xl |

```scss
.nav__menu {
  @include media-down(sm) {
    display: none;
  }
}
```

## states

Applies the full set of interactive states: disabled, hover, active and focus-visible. Ideal for buttons and interactive controls.

In a **filled** component (solid background with a label on top), pass in `$tint` the color opposite to the label: hover and pressed mix that color, the background moves away from the text and contrast goes up in those states. Without `$tint`, the states mix the color of the content itself, as in a surface component. The same `$tint` exists in `state-layer()` and `state-base()`.

```scss
@include states($focus-visible, $focus?, $bg?, $tint?)
```

| Parameter | Default | Values |
| --- | --- | --- |
| `$focus-visible` | `—` | primary \| secondary \| danger \| success \| neutral |
| `$focus` | `null` | primary \| secondary \| danger \| success \| neutral |
| `$bg` | `transparent` | Resting background color, e.g. `bg(container, primary)` |
| `$tint` | `null` | `tint(foreground)` for a light label · `tint(background)` for a dark label |

```scss
.menu-item {
  // Surface: the states mix the color of the content itself.
  @include states(primary);
}

.btn--primary {
  color: text(inverse);

  // Filled, light label: tint opposite to the label.
  @include states(primary, primary, $bg: bg(container, primary), $tint: tint(foreground));
}

.btn--neutral {
  color: text(body);

  // Filled, dark label.
  @include states(neutral, neutral, $bg: bg(container, neutral), $tint: tint(background));
}
```

## disabled

Applies only the disabled state styles (cursor, opacity, text-decoration). Use it when you do not need the other states of the states() mixin.

```scss
@include disabled
```

```scss
.link {
  @include disabled;
}
```

## focus-ring

Applies the visible focus box-shadow to the element's :focus-visible.

```scss
@include focus-ring($variant)
```

| Parameter | Default | Values |
| --- | --- | --- |
| `$variant` | `—` | primary \| secondary \| danger \| success \| neutral |

```scss
.input {
  @include focus-ring(primary);
}
```

## sr-only

Hides the element visually but keeps it available to screen readers. Equivalent to Tailwind's sr-only utility.

```scss
@include sr-only
```

```scss
.label--hidden {
  @include sr-only;
}
```

## no-select

Disables text selection with user-select: none.

```scss
@include no-select
```

```scss
.btn {
  @include no-select;
}
```

## font-scale

Applies a full type scale (font, size, weight, line-height, case) in a single call.

```scss
@include font-scale($scale-name)
```

| Parameter | Default | Values |
| --- | --- | --- |
| `$scale-name` | `—` | display \| title \| headline \| subtitle \| block-title \| subheadline \| overtitle \| body--lg \| body--md \| body--sm |

```scss
.page-title {
  @include font-scale(title);
}

.section-header {
  @include font-scale(headline);
}

.caption {
  @include font-scale(body--sm);
}
```
