---
title: "Functions"
subtitle: "SCSS functions defined in `packages/styles/src/utilities/_functions.scss`. Use them in components to reach design tokens safely — each function validates its argument and throws a compile error if the value does not exist in the token map."
---

```scss
// In the component file
@use '../utilities/functions' as *;

.my-component {
  background-color: bg(surface, primary);
  color: text(body);
  border-radius: radius(sm);
  padding: fluid(16);
}
```

## Colors

| Function | Description | Parameters |
| --- | --- | --- |
| `bg($category, $variant)` | Semantic background color. | `$category`: `surface`, `container` · `$variant`: `primary`, `secondary`, `info`, `danger`, `success`, `caution`, `neutral`, `overlay` (only in `container`) |
| `text($variant)` | Semantic text color. | `$variant`: `heading`, `body`, `caption`, `primary`, `inverse`, `error`, `link`, `link-visited` |
| `stroke($variant, $category?)` | Semantic border color. | `$variant`: `primary`, `secondary`, `caution`, `danger`, `info`, `success`, `neutral` · `$category`: `default` (default), `subtle`, `hover`, `pressed` |
| `icon($variant)` | Semantic icon color. | `$variant`: `primary`, `secondary`, `info`, `danger`, `success`, `caution`, `neutral`, `inverse` |
| `color($category, $scale)` | Primitive palette color. | `$category`: `primary`, `secondary`, `blue`, `gray`, `green`, `orange`, `red`, `violet` · `$scale`: `1` to `8` |
| `state($state, $bg?)` | Component background in a state: the tint mixed into the resting background. | `$state`: `hover`, `pressed` |
| `tint($role)` | State tint of a filled component, for the `$tint` parameter of `states()`, `state-layer()` and `state-base()`. They are the ends of the neutral scale and flip with the theme. | `$role`: `foreground` (near black in light, near white in dark), `background` (the opposite) |
| `state-amount($state)` | How much of the tint to mix. | `$state`: `hover`, `pressed` |

### Usage example — colors

```scss
.alert--danger {
  background-color: bg(container, danger);
  border-color: stroke(danger);
  color: text(body);

  .alert__icon { color: icon(danger); }
}

.btn--primary {
  color: text(inverse);

  // The state layer is the same for every variant and brand: the resting
  // background comes in through the mixin and the state rules mix a tint into it.
  // In a filled component, that tint is the color opposite to the label, so the
  // background moves away from the text and contrast goes up on hover and pressed.
  // `states()` already includes the layer; `$tint` swaps the tint.
  @include state-layer(bg(container, primary), tint(foreground));

  &:hover {
    background-color: state(hover);
    @include state-timing(hover);
  }

  &:active {
    background-color: state(pressed);
    @include state-timing(pressed);
  }
}
```

## Border

| Function | Value | Use |
| --- | --- | --- |
| `radius($size)` | `none` | No rounding. |
| | `xs` | Tags, badges, chips. |
| | `sm` | Buttons, inputs. |
| | `md` | Cards, modals. |
| | `lg` | Drawers, large surfaces. |
| | `xl` | Highlight containers. |
| | `circle` | Avatars, circular icons. |
| `width($size)` | `0` | No border. |
| | `1` | Default border, 1px. |
| | `2` | Emphasis and focus, 2px. |

```scss
.card    { border-radius: radius(md); border-width: width(1); }
.avatar  { border-radius: radius(circle); }
.focused { border-width: width(2); }
```

## Spacing

| fn | desc | values |
| --- | --- | --- |
| fixed($size) | Fixed spacing in px | 0,8,16,24,32,40 |
| fluid($size) | Fluid spacing with clamp() | 2,4,8,12,16,20,24,32,40,48,56,64,72,80 |

```scss
.section { padding: fluid(40); }
.card    { padding: fluid(24); gap: fixed(16); }
```

<Callout variant="tip">
Use `fluid()` for layout spacing (margins, gaps between blocks) and `fixed()` for the inner spacing of components that should not change with the viewport.
</Callout>

## Typography

| fn | prop | values |
| --- | --- | --- |
| font($font) | font-family | heading,body,code |
| size($size) | font-size | 3xl,2xl,1xl,lg,md,sm,1xs,2xs,3xs |
| weight($weight) | font-weight | regular,medium,semibold,bold |
| line-height($lh) | line-height | heading,body |
| case($case) | text-transform | none,lowercase,uppercase |
| decoration($decoration) | text-decoration | none,underline,line-through |

```scss
.heading--title {
  font-family: font(heading);
  font-size: size(2xl);
  font-weight: weight(bold);
  line-height: line-height(heading);
}
```

<Callout variant="tip">
To apply full type scales, prefer the `font-scale($scale-name)` mixin.
</Callout>

## States and elevation

| fn | desc | values |
| --- | --- | --- |
| focus-ring($variant) | Focus box-shadow | primary,secondary,danger,success,neutral |
| elevation($layer) | Elevation box-shadow | base,hovered,floating,overlay |
| opacity($category) | Semantic opacity | disabled,hidden,visible |
| breakpoint($name) | Responsive breakpoint value | 1xs (767px, ceiling),sm (768px),md (1024px),lg (1280px),1xl (1440px) |
| step-above($name) | Next step of the breakpoint scale | 1xs,sm,md,lg |
| grid($category, $name) | Value from the grid table | columns,gap,margin,container |

```scss
.modal   { box-shadow: elevation(overlay); }
.tooltip { box-shadow: elevation(floating); }

.btn:focus-visible { box-shadow: focus-ring(primary); }
.btn:disabled      { opacity: opacity(disabled); }

@media (min-width: breakpoint(md)) {
  .sidebar { display: block; }
}
```

<Callout variant="tip">
  For responsiveness, prefer the `media-up()` and `media-down()` mixins over calling `breakpoint()` directly. They are exact complements of each other (`media-down()` applies strictly below the step's floor), while a hand-written `max-width` tends to leave a gap at fractional widths.
</Callout>

`breakpoint()` and `grid(columns, …)` are the only two functions that return a
literal value instead of a `var()`. They are read at compile time — by a media
query prelude and by the `@for` that generates the `.col-*` classes — and
neither can read a custom property. The other `grid()` categories (`gap`,
`margin`, `container`) return `var()` and keep following `data-brand` at runtime.
