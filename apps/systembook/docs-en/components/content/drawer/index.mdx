## Best practices

<DosDonts variant="do" title="Details without leaving the page">
  See the details of a table item without losing sight of the list.
</DosDonts>

<DosDonts variant="do" title="Editing a record">
  Forms that need more space than a [Modal](../modal/index.mdx).
</DosDonts>

<DosDonts variant="do" title="Filters and settings">
  Adjustments the person applies without losing the page context.
</DosDonts>

<DosDonts variant="dont" title="Short confirmations">
  Use a [Modal](../modal/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Messages and warnings">
  Use [Alert](../alert/index.mdx) or [Toast](../toast/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Content that deserves a page">
  Long flows should have their own screen.
</DosDonts>

<DosDonts variant="dont" title="Main navigation">
  Use a menu or [Sidebar](../../layout/sidebar/index.mdx).
</DosDonts>

## Anatomy

![Anatomy of the open Drawer: backdrop, panel, header, body and footer](./anatomy.png)

1. **Backdrop**: darkens the page behind the panel.
2. **Panel**: the surface that slides in from the right.
3. **Header**: title and close button.
4. **Body**: the main content, which scrolls if it is long.
5. **Footer** (optional): action buttons, fixed at the bottom.

## Sizes

| Size | When to use |
| --- | --- |
| `sm` | Simple panels, few fields. |
| `md` (default) | Most cases. |
| `lg` | Content with a lot of information. |

## Behavior

- It opens by sliding in from the **right**, with a backdrop over the page.
- Focus moves into the panel, and the page behind is inaccessible while it is open.
- It closes with the close button, with "Cancel", with `Esc` and, if enabled, by clicking the backdrop.
- On closing, focus returns to the element that opened it.

## No actions

If the Drawer is only informative, or if the actions are already part of the content, omit the footer.
