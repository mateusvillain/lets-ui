## Positions

Use the `position` attribute to control where the tooltip appears relative to its trigger.

## Custom Trigger

Slot any focusable element inside `<lui-tooltip>` to use it as the trigger. The component automatically wires up `aria-describedby` on focusable children.

## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `text` | `string` | `Tooltip` |
| `position` | `string` | `top` |
| `label` | `string` | `Show tooltip` |
| `aria-label` | `string` | `''` |

## Usage

### Web Component

```html
<lui-tooltip text="Tooltip text" position="top" label="Hover here"></lui-tooltip>
```

### CSS class

```html
<div class="tooltip tooltip--top">
  <button class="tooltip__trigger">Hover here</button>
  <div role="tooltip" class="tooltip__content">Tooltip text</div>
</div>
```

With the class alone, the tooltip can already receive the pointer and respects `prefers-reduced-motion`. Closing with `Esc` requires a script: add `tooltip--dismissed` to the `.tooltip` element when `Esc` is pressed while it is open, and remove the class on the next `pointerenter` or `focusin`.

```js
const tooltip = document.querySelector('.tooltip');

document.addEventListener('keydown', (event) => {
  if (event.key !== 'Escape' || event.isComposing || event.repeat) return;
  if (!tooltip.matches(':hover, :focus-within')) return;
  if (tooltip.classList.contains('tooltip--dismissed')) return;
  tooltip.classList.add('tooltip--dismissed');
  event.preventDefault();
});

const restore = () => tooltip.classList.remove('tooltip--dismissed');
tooltip.addEventListener('pointerenter', restore);
tooltip.addEventListener('focusin', restore);
```
