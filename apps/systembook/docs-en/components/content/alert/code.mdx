## Dismissible

Add the `dismissible` attribute to show a close button in the corner of the alert. When clicked, the component emits the `lui-dismiss` event — use it to remove the alert from the DOM or update the application state.

The button's accessible label can be customized with the `close-label` attribute (default: `"Close"`).

## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `variant` | `string` | `success` |
| `title` | `string` | `''` |
| `content` | `string` | `''` |
| `dismissible` | `boolean` | `false` |
| `close-label` | `string` | `Close` |

## Usage

### Web Component

```html
<lui-alert variant="info" title="Title" content="Important information"></lui-alert>
```

### Dismissible

```html
<lui-alert
  variant="caution"
  title="Warning"
  content="This action cannot be undone."
  dismissible
  close-label="Close alert"
></lui-alert>

<script>
  document.querySelector('lui-alert').addEventListener('lui-dismiss', (e) => {
    e.target.remove();
  });
</script>
```

### CSS class

```html
<div class="alert alert--info">
  <div class="alert__content">
    <div class="alert__text">
      <p>Important information</p>
    </div>
  </div>
</div>
```
