## Photo

With `src`, the avatar shows the image, cropped to cover the shape. The photo is decorative for the screen reader, because the name is already on the avatar.

If the image fails to load, the avatar falls back to the initials. Changing `src` tries again.

## No photo and no initials

Without `src`, `initials` and `name`, the avatar shows a person icon. It uses the initials color of the `variant`, and stays out of the accessibility tree.

## Status

`status` draws an indicator in the bottom-right corner: `online`, `away`, `busy` or `offline`.

<ComponentEmbed component="Avatar" variant="status" />

The dots measure 10, 12 and 16px at `sm`, `md` and `lg`.

### Status shape

Each status has its own shape inside the dot, in addition to color, so that people who cannot tell the colors apart can still tell the states apart: `online` is filled, `away` shows clock hands, `busy` a bar and `offline` an empty center. The shapes are measured on the area inside the dot's ring and scale with the size. At `sm` the dot is 10px and the shapes get very small, so prefer `md` or `lg` when the status difference matters.

### Status text

In both modes the status goes into the accessible name as text: "Mateus Villain, Online". The default texts are in English. Change them with `status-label`.

## Decorative

An avatar without `name` and without `status` has no accessible name, so it stays hidden from assistive technology.

## Group

`lui-avatar-group` stacks the avatars with an overlap of 30% of the size and a ring in the surface color, which keeps each one's edge legible. The group's `size` applies to all avatars, and an avatar can have its own.

Inside a group, the status dot moves to the bottom-left corner, the corner the next avatar leaves free. The overlap follows each avatar's size, not the group's.

## CSS class (without Web Component)

Without the Web Component, the markup is up to you. The wrapper takes `role="img"` and `aria-label`, and what is inside it takes `aria-hidden="true"` (initials and status dot) or `alt=""` (photo). The fallback for a photo that fails does not exist in this version.

## Properties

### `lui-avatar`

| Attribute      | Type     | Default  | Description                                                                                  |
| -------------- | -------- | -------- | -------------------------------------------------------------------------------------------- |
| `name`         | `string` | `''`     | The person's name. Becomes the accessible name and the source of the initials.               |
| `src`          | `string` | `''`     | Photo URL. If it fails, shows the initials or the icon.                                      |
| `initials`     | `string` | `''`     | Initials to show. If omitted, they come from `name`.                                         |
| `variant`      | `string` | `gray`   | `gray`, `blue`, `green`, `orange`, `red` or `violet`.                                        |
| `size`         | `string` | `''`     | `sm`, `md` or `lg`. Empty means `lg`, or the group's size.                                   |
| `radius`       | `string` | `circle` | `circle`, `rounded` or `square`.                                                             |
| `status`       | `string` | `''`     | `online`, `away`, `busy` or `offline`. Empty draws no indicator.                             |
| `status-label` | `string` | `''`     | Status text for the screen reader. If omitted: "Online", "Away", "Busy" or "Offline".        |

### `lui-avatar-group`

| Attribute | Type     | Default | Description                                                        |
| --------- | -------- | ------- | ------------------------------------------------------------------ |
| `label`   | `string` | `''`    | Accessible name of the group, such as "Project members".           |
| `size`    | `string` | `''`    | `sm`, `md` or `lg`. Applies to avatars that do not set their own.  |

| Slot      | Description                 |
| --------- | --------------------------- |
| (default) | The group's `lui-avatar` elements. |

## Usage

### Web Component

```html
<lui-avatar name="Mateus Villain" status="online"></lui-avatar>

<lui-avatar name="Ana Lima" src="/fotos/ana.jpg" size="md" radius="rounded">
</lui-avatar>

<lui-avatar-group label="Project members" size="md">
  <lui-avatar name="Ana Lima" variant="blue"></lui-avatar>
  <lui-avatar name="Bia Souza" variant="green"></lui-avatar>
  <lui-avatar name="Caio Reis" variant="orange"></lui-avatar>
</lui-avatar-group>
```

### CSS class

```html
<span
  class="avatar avatar--lg avatar--circle avatar--blue"
  role="img"
  aria-label="Mateus Villain, Online"
>
  <span class="avatar__initials" aria-hidden="true">MV</span>
  <span class="avatar__status avatar__status--online" aria-hidden="true"></span>
</span>
```
