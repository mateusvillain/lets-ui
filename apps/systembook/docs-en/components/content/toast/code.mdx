## Custom icon

The icon can be customized in every variant through the `icon` slot. Each variant comes with a default outline icon — `bell` (`default`), `circle-check` (`success`) and `circle-x` (`danger`) — which is replaced automatically when something is passed in the slot.

## Content (default slot)

The secondary description can be passed in two ways: as direct children of the element (default/unnamed slot — the recommended way, used in most examples on this page) **or** through the `content` attribute (plain text, always escaped). When there is real content in the default slot, it takes priority over `content`; otherwise, `content` is used as a fallback.

## Auto-dismiss

By default, the toast disappears on its own after `duration` milliseconds (default `5000`). Hovering over the toast, or moving keyboard focus into it, pauses the countdown; it resumes where it stopped when the pointer leaves or focus moves out.

## Persistent

Use `duration="0"` to disable auto-dismiss entirely — the toast stays until it is closed manually.

## Danger never disappears on its own

`variant="danger"` always behaves as persistent and ignores any `duration` value, even when explicitly set. This is a deliberate accessibility decision (see the section below), not a bug.

## With action

The action button is optional and always sits on the right. **When an action button is present, the close button (X) is not rendered** — clicking anywhere in the action area dismisses the toast (in addition to firing the button's normal click). This means that, if the consumer uses an action button in a `danger` toast, it becomes the only way to dismiss it.

### With action — all variants

The `variant` of the action button is chosen by the consumer (it is not derived automatically from the toast's `variant`) — match them manually to keep visual consistency, as in the example below.

## Positioning

By default, `.toast-region` is fixed at the bottom center of the screen, with ~24px of breathing room from the edge (mobile/Android pattern — see `.study/toast.md` §10). Other positions are opt-in through a modifier on the class itself:

```html
<div class="toast-region toast-region--top-right" role="region" aria-label="Notifications">...</div>
```

Available modifiers: `--top-left`, `--top-center`, `--top-right`, `--bottom-left`, `--bottom-center` (same as the default), `--bottom-right`. On screens `< 768px` the region always takes the full width (minus a 16px margin on each side) and is anchored at the bottom, respecting `env(safe-area-inset-bottom)`, regardless of the chosen modifier.

## Stacked

Multiple `<lui-toast>` elements inside the same `.toast-region` collapse visually into a stack: the last element in the DOM sits in front at normal scale, and the previous ones recede behind it at 95% scale, peeking slightly over the top — without a messy overlap. Stacking/positioning is still CSS only in this release — there is no imperative queue API (`toast.show()`) yet (planned as a follow-up).

## XSS-safe content

`title` and the `content` attribute are interpolated as plain text through Lit's `html` template (with automatic escaping) — HTML-like strings are rendered literally, never as markup or script. **This guarantee applies only to the `content` attribute.** If you use the default slot instead of the attribute, the content passed is real HTML in the light DOM and is not escaped — never insert text from an untrusted source directly into the slot without sanitizing it first.

## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `variant` | `string` | `default` |
| `title` | `string` | `''` |

| `duration` | `number` | `5000` |
| `close-label` | `string` | `Close` |

## Usage

### Web Component

The `.toast-region` container must be a navigation landmark (`role="region"` + `aria-label`) so that keyboard/screen reader users can reach it through landmark navigation (F6):

```html
<div class="toast-region" role="region" aria-label="Notifications">
  <lui-toast variant="default" title="Title">Important information</lui-toast>
</div>
```

### Custom icon

```html
<lui-toast variant="default" title="New follower" content="Ana started following you.">
  <svg slot="icon" viewBox="0 0 24 24" fill="currentColor" aria-hidden="true">...</svg>
</lui-toast>
```

### Content through the slot (instead of the attribute)

```html
<lui-toast variant="success" title="Changes saved">
  Your data has been updated. <a href="/profile">View profile</a>.
</lui-toast>
```

### With action

```html
<lui-toast variant="success" title="Changes saved" content="Your data has been updated.">
  <lui-button slot="action" variant="success" label="View"></lui-button>
</lui-toast>
```

### Manual close

The component emits the `lui-close` event (`bubbles`, `composed`) on manual close (X or a click in the action area) and on auto-dismiss.

```html
<script>
  document.querySelector('lui-toast').addEventListener('lui-close', (e) => {
    // e.target removes itself from the DOM after the exit animation;
    // use this event to sync application state (e.g. a toast queue).
  });
</script>
```

### CSS class

```html
<div class="toast">
  <div class="toast__text">
    <p>Important information</p>
  </div>
</div>
```

## API Reference

| Prop/Attribute | Type                              | Default     | Description                                                                      |
| --------------- | ----------------------------------- | ------------- | ------------------------------------------------------------------------------------ |
| `variant`       | `default` \| `success` \| `danger` | `default`   | Semantic variant — controls the default icon, the icon color and the ARIA role.     |
| `title`         | `string`                            | `''`          | Short main message.                                                                  |
| `content`       | `string`                            | `''`          | Optional secondary description. Serves as the default slot's fallback — ignored if there is real slotted content. |
| `duration`      | `number` (ms)                       | `5000`        | Auto-dismiss delay. `0` disables it. Ignored when `variant="danger"`.                |
| `close-label`   | `string`                            | `'Close'`     | Accessible label of the close button (only rendered when there is no slotted `action`). |

### Slots

| Slot                | Description                                                                                     |
| ------------------- | --------------------------------------------------------------------------------------------------- |
| _(default/unnamed)_ | Secondary description, with markup support (e.g. links). Replaces the `content` attribute when present. |
| `icon`              | Custom icon. Outline fallback per variant: bell (`default`), circle-check (`success`), circle-x (`danger`). |
| `action`            | Optional action button, aligned to the right. When present, it replaces the close button (X).       |

### Events

| Event       | Detail | When                                                                             |
| ----------- | ------ | ------------------------------------------------------------------------------------ |
| `lui-close` | —      | Fired on manual close (X, `Esc`, click in the action area) and on auto-dismiss.    |
