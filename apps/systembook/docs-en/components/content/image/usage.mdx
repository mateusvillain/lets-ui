## Choose good images

- Use images that **add information**, not just decoration.
- Keep the same aspect ratio across images in the same set (all 16:9, for example).
- Ensure quality on high-density screens, with versions at twice the displayed size.

<DosDonts variant="do" title="Reserve the space">
  Set the aspect ratio so the page does not "jump" when the image loads.
</DosDonts>

<DosDonts variant="dont" title="Stretch or distort">
  Changing the image's aspect ratio to fit the space. Use `fit="cover"` to crop carefully, or adjust the image framing.
</DosDonts>

## Alternative text

Every content image needs an `alt`: a short description of what it **communicates**, not of what it is.

| Image | Bad alt | Good alt |
| --- | --- | --- |
| Sales chart | "Chart" | "Sales rose 20% in March" |
| Product photo | "Image" | "Blue running shoe, side view" |
| Purely decorative image | "Blue background" | (empty: `alt=""`) |

## Caption

Use a caption when there is complementary information: authorship, location, date, description. Avoid captions that repeat the `alt`.

## Loading

- Images **below the fold** load lazily (default).
- The **main** image of the page, which appears right at the top, should load immediately (`loading="eager"`).
- Choose a **fallback color** close to the image, so the space does not look empty.
- Provide an alternative image (`fallback-src`) for important cases.

## Best practices

- Optimize file weight and use modern formats.
- Use `as="picture"` when you need different versions for different screen sizes.
- Do not put important text inside the image. Screen readers do not read it, and it does not adapt to the language.
