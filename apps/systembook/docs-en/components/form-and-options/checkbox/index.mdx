## Best practices

<DosDonts variant="do" title="Select several items">
  Interests, permissions or filters from a list.
</DosDonts>

<DosDonts variant="do" title="Confirm an option on submit">
  A yes or no that only takes effect after the form is submitted, such as "I have read and accept the terms".
</DosDonts>

<DosDonts variant="dont" title="Choosing only one option">
  Use the [Radio Group](../radio-group/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Immediate effect on toggle">
  To turn on notifications, for example, use the [Switch](../switch/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Choosing among many options">
  With more than seven options, use a [Select](../select/index.mdx) or a searchable list.
</DosDonts>

## Anatomy

![Checkbox anatomy: box and label in the checked state, and error message](./anatomy.png)

1. **Box**: shows the checked or unchecked state.
2. **Label**: describes the option. Clicking it also toggles the box.
3. **Error message** (optional): appears when the choice is required and missing.

## States

| State | Description |
| --- | --- |
| **Unchecked** | The option is not chosen. |
| **Checked** | The option is chosen. |
| **Focus** | The box has a focus ring when navigating by keyboard. |
| **Error** | The choice is required and was not made. |
| **Disabled** | It cannot be changed right now. |

## Sizes

`lg` (default) and `md`. Use the same size within a group.

## Related

- [Radio Group](../radio-group/index.mdx): a single choice.
- [Switch](../switch/index.mdx): turn on and off with immediate effect.
- [Select](../select/index.mdx): one option from a long list.
