## Hint

Helper text shown below the options. Replaced by the `error-text` message when `error` is `true`.

<ComponentEmbed component="RadioGroup" variant="hint" />

## Small

`size="md"` applies `body--md` to the group label, following the same pattern as `lui-input`.

## Preselected

Add `checked` to the desired `lui-radio` to set an initial value. The group syncs the `FormData` automatically on connect.

## Disabled

`disabled` on the group propagates the state to all children and excludes the field from submission.

## Form integration

### Required

`required` on the group blocks submission while no option is selected. The `invalid` event fires on the group and the `error-text` message is shown below the options, representing the group as a whole.

### Form Integration

The selected value is submitted in the `FormData` under the group's `name` key. Multiple independent groups coexist in the same form without interfering.

## Attributes

| Attribute    | Type      | Default                 | Description                                                       |
| ------------ | --------- | ----------------------- | ----------------------------------------------------------------- |
| `name`       | `string`  | `''`                    | Field key in the `FormData`                                       |
| `label`      | `string`  | `''`                    | Text shown as the group's `<legend>`                              |
| `size`       | `'lg' \| 'md'` | `'lg'`            | Label size: `lg` → `body--lg`, `md` → `body--md`                 |
| `hint`       | `string`  | `''`                    | Helper text below the options; replaced by `error-text` on error  |
| `required`   | `boolean` | `false`                 | Blocks submission when no option is selected                      |
| `disabled`   | `boolean` | `false`                 | Disables all child radios and excludes the field from submission  |
| `error`      | `boolean` | `false`                 | Turns on the error state manually                                 |
| `error-text` | `string`  | `'Select an option.'`| Message shown below the group when `error` is true                |
| `form`       | `string`  | `''`                    | ID of the associated `<form>`; lets you use the group outside the `<form>` |

## Usage

### Web Component

```html
<lui-radio-group name="plan" label="Plan" size="lg">
  <lui-radio value="basic" label="Basic"></lui-radio>
  <lui-radio value="pro" label="Pro"></lui-radio>
</lui-radio-group>
```

### CSS class

```html
<fieldset class="radio-group radio-group--lg">
  <legend class="radio-group__legend">Plan</legend>
  <div class="radio-group__options">
    <label class="radio">
      <input type="radio" name="plan" value="basic"> Basic
    </label>
    <label class="radio">
      <input type="radio" name="plan" value="pro"> Pro
    </label>
  </div>
</fieldset>
```
