## Best practices

<DosDonts variant="do" title="Choosing exactly one option">
  Between two and seven options, always inside a [Radio Group](../radio-group/index.mdx).
</DosDonts>

<DosDonts variant="do" title="All options in view">
  When the person needs to see the options at the same time to choose.
</DosDonts>

<Callout variant="info">
  The Radio does not live on its own. To build a complete choice, with a title, hint and error, use the [Radio Group](../radio-group/index.mdx), which organizes the Radios.
</Callout>

<DosDonts variant="dont" title="Several options at once">
  Use the [Checkbox](../checkbox/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Turning on or off">
  Use the [Switch](../switch/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="More than seven options">
  Use a [Select](../select/index.mdx).
</DosDonts>

## Anatomy

![Radio anatomy: circle and label](./anatomy.png)

1. **Circle**: shows whether the option is chosen.
2. **Label**: describes the option. Clicking it also chooses the Radio.

## States

| State | Description |
| --- | --- |
| **Unselected** | The option was not chosen. |
| **Selected** | The option is chosen. Only one per group. |
| **Focus** | Focus ring when navigating by keyboard. |
| **Error** | The group requires a choice and it was not made. |
| **Disabled** | The option is not available. |
