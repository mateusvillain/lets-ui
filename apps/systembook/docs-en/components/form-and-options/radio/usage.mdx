## Option labels

- Use **short, distinct** labels.
- Each option must be **mutually exclusive**: no situation can fit two of them.
- Sentence case and no ending punctuation.

## Preselected option

Preselect the **safest or most common** option, when there is one. If the choice is important and there is no reasonable default, leave it unselected and mark the group as required.

<DosDonts variant="do" title="Sensible default">
  Preselect "Standard shipping" in a shipping choice. The person only changes it if they want to.
</DosDonts>

<DosDonts variant="dont" title="Default that only benefits the company">
  Preselecting the most expensive plan or an option that shares data. It misleads instead of helping.
</DosDonts>

## Position and alignment

Align the Radios **vertically**, one below the other, with the same label width. Reading in a column is faster than in a row.

Use a horizontal layout only with two or three very short options.

## Best practices

- Do not allow a selected Radio to be unchecked. If the person needs to be able to "not choose", include a "None" option.
- Keep the options visible. If there are many, switch to a [Select](../select/index.mdx).
- All options in the group use the same size.
