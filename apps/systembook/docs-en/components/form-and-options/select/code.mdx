## Form integration

`lui-native-select` is form-associated. The selected option's value is submitted via `FormData` under the `name` key. Use `form` to associate it with a form by ID even when it sits outside the `<form>`.

### Required

With `required`, the form does not submit while the placeholder is active (no real option selected).

## Form attributes

| Attribute  | Type      | Default | Description                                                                      |
| ---------- | --------- | ------ | -------------------------------------------------------------------------------- |
| `name`     | `string`  | `''`   | Field name in the submitted data; required to appear in the `FormData`           |
| `form`     | `string`  | `''`   | ID of the associated `<form>`; lets you use the select outside the form element  |
| `required` | `boolean` | `false`| Blocks submission while the placeholder is selected                              |

## Usage

### Web Component

```html
<lui-native-select
  label="Country"
  placeholder="Select..."
  options="Brazil,Portugal"
  size="lg"
></lui-native-select>
```

### CSS class

```html
<div class="native-select native-select--lg">
  <div class="native-select__head">
    <label class="native-select__label">Country</label>
  </div>
  <div class="native-select__control">
    <select class="native-select__input">
      <option value="">Select...</option>
      <option value="br">Brazil</option>
    </select>
    <span class="native-select__arrow">
      <svg ...>...</svg>
    </span>
  </div>
</div>
```
