## Position

Place the Breadcrumb **at the top of the content**, above the page title and below the global header. On every page, in the same position.

## Reflect the site structure

<DosDonts variant="do" title="Site hierarchy">
  "Home › Components › Buttons". Each item is a real ancestor page, and the person understands the structure.
</DosDonts>

<DosDonts variant="dont" title="Browsing history">
  Showing the last visited pages is confusing, because the path changes depending on how the person got there. The Breadcrumb is a map, not a history.
</DosDonts>

## Write the items

- Use the **same name as the title** of the destination page.
- Prefer short labels. If a name is long, let the layout truncate it instead of abbreviating it yourself.
- Do not include the current page as a link.

## Long paths

In deep hierarchies, keep the first item (home) and the last levels, and group the intermediate ones. On small screens, show at least the **level immediately above**, to allow "going back one level".

## Best practices

- Do not use the Breadcrumb as the only means of navigation.
- Do not repeat the Breadcrumb more than once on the page.
- Keep the behavior consistent across the whole product.
