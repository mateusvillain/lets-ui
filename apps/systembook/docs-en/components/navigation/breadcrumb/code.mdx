## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `aria-label` | `string` | `Breadcrumb` |

## Usage

### Web Component

```html
<lui-breadcrumb aria-label="Breadcrumb">
  <lui-breadcrumb-item href="#">Home</lui-breadcrumb-item>
  <lui-breadcrumb-item href="#">Category</lui-breadcrumb-item>
  <lui-breadcrumb-item active>Current page</lui-breadcrumb-item>
</lui-breadcrumb>
```

### CSS class

```html
<nav aria-label="Breadcrumb">
  <ol class="breadcrumb">
    <li><a href="#">Home</a></li>
    <li><a href="#">Category</a></li>
    <li aria-current="page">Current page</li>
  </ol>
</nav>
```
