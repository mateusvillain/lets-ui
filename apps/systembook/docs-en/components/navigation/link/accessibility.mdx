## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves focus to the link. |
| `Enter` | Follows the link. |

A disabled link stays focusable, so keyboard and screen reader users know it exists and is unavailable.

## Screen reader

- The link is announced as a **link**, with its text as the name.
- If the text does not describe the destination ("Read more"), use `aria-label` with a full description, like "Read more about accessibility".
- Disabled links are announced as unavailable (`aria-disabled`).
- When opening in a new tab, the link gets `rel="noopener noreferrer"` automatically, for security.
- As the trigger of a Modal or Drawer, the link gets `aria-expanded` and `aria-haspopup` from the component itself and passes them to the inner `<a>`.

## Visual

- The link text has a minimum contrast of 4.5:1 against the background.
- The underline and the focus ring appear on hover and on keyboard focus.
- The visited link color also meets the contrast requirement.

## For designers

- Do not rely on color alone to identify links inside text.
- Avoid several links with the same text and different destinations on the same page.
- Say when the link opens in another tab or downloads a file.
