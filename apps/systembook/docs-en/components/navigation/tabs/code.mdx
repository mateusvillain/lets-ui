## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `variant` | `string` | `line` |
| `expand` | `boolean` | `false` |

## Usage

### Web Component

```html
<lui-tabs variant="line">
  <lui-tab label="General" active><p>Content of the General tab.</p></lui-tab>
  <lui-tab label="Security"><p>Content of the Security tab.</p></lui-tab>
</lui-tabs>
```

### CSS class

```html
<div class="tabs tabs--line">
  <div class="tabs__list">
    <button class="tab" role="tab" aria-selected="true">General</button>
    <button class="tab" role="tab" aria-selected="false">Security</button>
  </div>
  <div class="tabs__panel" role="tabpanel">Content of the General tab</div>
  <div class="tabs__panel" role="tabpanel" hidden>Content of the Security tab</div>
</div>
```
