---
title: "Accessibility"
---

Switcher is layout only and **adds no semantics**.

- **Reading order**: the same as the source, both in a row and stacked.
- **Reflow**: when text is enlarged or space shrinks, items stack, without horizontal scrolling. That is what the component guarantees.
- **Content**: each item needs to make sense on its own, because their relative position changes depending on the space.
