## Best practices

<DosDonts variant="do" title="Sections of a menu">
  Groups of items on different subjects.
</DosDonts>

<DosDonts variant="do" title="Action groups and form sections">
  Blocks that belong to different subjects.
</DosDonts>

<DosDonts variant="do" title="Sign-in alternatives">
  The "or" between two sign-in options.
</DosDonts>

<DosDonts variant="dont" title="Creating space">
  Use the spacing of [Stack](../stack/index.mdx) or [Box](../box/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Separating every item in a list">
  Too many lines add clutter. Use space, or the dividers of [Table](../../content/table/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Separating headings from content">
  Typography already creates the hierarchy.
</DosDonts>

## Variations

| Variation | When to use |
| --- | --- |
| **Horizontal** (default) | Separates stacked blocks: menus, sections, forms. |
| **Vertical** | Separates side-by-side items, as in toolbars. |
| **With text** (`label`) | Separator with a word, such as "or". |
