## Usage

### Web Component

```html
<lui-flex gap="md" align="stretch" justify="start">
  <lui-flex-item grow="1">Grows</lui-flex-item>
  <lui-flex-item>Fixed</lui-flex-item>
</lui-flex>
```

### CSS class

```html
<div class="flex flex--gap-md flex--align-center">
  <div class="flex-item--grow">Grows</div>
  <div class="flex-item--shrink-0">Fixed</div>
</div>
```
