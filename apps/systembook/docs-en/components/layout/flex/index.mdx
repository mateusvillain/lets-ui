## Container options

| Option | What it controls |
| --- | --- |
| `direction` | Row or column, normal or reversed. |
| `wrap` | Whether items wrap to a new line. |
| `gap` (`gap-x`, `gap-y`) | Space between items. |
| `align` | Alignment on the cross axis. |
| `justify` | Distribution on the main axis. |
| `inline` | Inline container, not block. |

## Flex Item

`lui-flex-item` controls a single item: how much it grows (`grow`), shrinks (`shrink`), its base size (`basis`), its own alignment (`align`) and its order (`order`).
