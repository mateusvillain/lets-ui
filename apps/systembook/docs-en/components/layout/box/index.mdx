## What Box controls

| Option | What it controls |
| --- | --- |
| `padding`, `padding-x`, `padding-y` | Padding, from the system scale. |
| `background` | Background, by a semantic name such as `neutral/surface` or `primary/container`. |
| `border-radius` | Rounding: `none`, `xs`, `sm`, `md`, `lg`, `xl` or `circle`. |
| `border-width`, `border-color` | Border width (0, 1, 2 or 4) and color. |
| `overflow` | How content that goes past the edge is handled. |

Because it uses tokens, Box changes on its own with the **theme** (light and dark) and the **brand**.

## Semantic backgrounds

Backgrounds follow roles: **surface** (subtle) and **container** (emphasis) for the `neutral`, `primary`, `secondary`, `info`, `success`, `caution` and `danger` families. Choose by the **meaning** of the content.
