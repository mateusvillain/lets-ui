---
title: "Accessibility"
---

Box is only a surface and **adds no semantics**. Use the `as` option to render the right element (`section`, `aside`, `article`) when it represents a region.

- **Contrast**: text on any Box background needs 4.5:1. The system tokens were designed for this, but test unusual combinations.
- **State**: do not rely on the background color alone (such as `danger/surface`) to convey a state. Include text and, if possible, an icon.
