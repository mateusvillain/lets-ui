---
title: "Accessibility"
---

Float only **positions**. What matters for accessibility is the content you put in it.

- **Indicators**: a notification dot or a counter needs a **text equivalent** for screen readers. For example, "3 new messages" in the button's name.
- **Decorative**: if the element is only decoration, hide it from assistive technology.
- **Overlap**: do not cover text or controls. Make sure the touch area of the element underneath stays accessible.
- **Contrast**: the floating element must contrast with what is underneath (3:1 for graphics, 4.5:1 for text).
