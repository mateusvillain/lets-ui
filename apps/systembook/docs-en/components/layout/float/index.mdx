## Placements

Nine positions, combining **top, middle and bottom** with **start, center and end** (`placement`). The default is `bottom-end`.

<ComponentEmbed component="Float" variant="bottom-end" />

## Offset

`offset-x` and `offset-y` move the element from the chosen position, in pixels. Use negative values to make it "stick out" of the corner, like a badge that extends past the icon.
