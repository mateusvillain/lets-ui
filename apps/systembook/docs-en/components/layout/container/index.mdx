## Best practices

<DosDonts variant="do" title="Readable width">
  Text does not stretch across wide screens.
</DosDonts>

<DosDonts variant="do" title="Content centered on the page">
  Container limits the width and centers the content.
</DosDonts>

<DosDonts variant="dont" title="Structuring columns">
  Use [Grid](../grid/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="A surface with background or border">
  Use [Box](../box/index.mdx) or [Card](../../content/card/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Content that fills the whole screen">
  For maps and editors, use the full-width variant.
</DosDonts>

## Sizes

| Size | When to use |
| --- | --- |
| `sm` | Reading content and narrow forms. |
| `md` | Intermediate content pages. |
| `lg` (default) | Content pages and dashboards. |
| `full` | Full width, no limit. |

## Options

`padding` sets the side spacing (default 32) and `center` controls centering.
