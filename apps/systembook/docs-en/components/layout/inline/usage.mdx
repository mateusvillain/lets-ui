## Action groups

In a group of buttons, use a `gap` of 8 or 16 so each button has its own area. Align to the end in forms and dialogs, with `justify="end"`.

## Tag and filter groups

Inline is the right choice for tags and filters because it **wraps** on its own when space runs out, without overflowing the container.

<DosDonts variant="do" title="Let it wrap">
  Tags that move to the line below when space runs out. Nothing gets clipped.
</DosDonts>

<DosDonts variant="dont" title="Forcing a single line without scrolling">
  Turning off wrapping with many items would clip content or cause unexpected horizontal scrolling.
</DosDonts>

## Space between lines

When items wrap, use a `gap-y` smaller than `gap-x` so the lines stay cohesive without touching.

## Best practices

- Keep items the same height whenever possible.
- In action bars, place the primary action last.
- For elements with very different widths, test with the longest text.
