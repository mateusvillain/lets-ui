## Options

| Option | What it controls | Default |
| --- | --- | --- |
| `gap` (`gap-x`, `gap-y`) | Space between items. | 8 |
| `align` | Vertical alignment. | Center |
| `justify` | Horizontal distribution. | Start |
| `wrap` | Whether items wrap to a new line. | Wrap |
