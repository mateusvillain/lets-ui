## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `gap` | `string` | `8` |
| `gap-x` | `string` | `''` |
| `gap-y` | `string` | `''` |
| `align` | `string` | `center` |
| `justify` | `string` | `start` |
| `wrap` | `string` | `wrap` |

## Usage

### Web Component

```html
<lui-inline gap="sm" align="center" justify="start" wrap="wrap">
  <span>Design</span>
  <span>Engineering</span>
  <span>Product</span>
</lui-inline>
```

### CSS class

```html
<div class="inline inline--gap-sm">
  <span>Design</span>
  <span>Engineering</span>
  <span>Product</span>
</div>
```
