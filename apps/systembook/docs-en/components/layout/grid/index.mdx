## The grid

The grid is **mobile-first**. The number of columns and the space between them vary by breakpoint:

| Breakpoint | Screen | Columns | Gap | Side margin |
| --- | --- | --- | --- | --- |
| base | up to 767px | 4 | 16px | 16px |
| `sm` | from 768px | 8 | 16px | 32px |
| `md` | from 1024px | 8 | 16px | 40px |
| `lg` | from 1280px | 12 | 24px | 40px |
| `1xl` | from 1440px | 12 | 24px | 1360px container, centered |

These values come from the brand tokens, so a brand can redefine the whole grid.

## Items

Each `lui-grid-item` chooses **how many columns it spans** at each breakpoint (`col`, `col-sm`, `col-md`, `col-lg` and `col-1xl`). A declared value applies from there upward, until another one overrides it.

## Nested grid

A Grid inside an item gets `flush` automatically, so the side margin is not repeated.
