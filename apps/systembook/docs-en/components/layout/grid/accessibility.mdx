---
title: "Accessibility"
---

Grid is layout only and **adds no semantics**.

- **Source order**: reading and focus order follow the source. Do not reorder visually in a way that differs from the content order.
- **Reflow**: on mobile and at 200% zoom, the columns rearrange into fewer columns, without horizontal scrolling.
- **Regions**: use semantic elements (`header`, `main`, `nav`, `aside`) in the grid areas to create landmarks for screen readers.
