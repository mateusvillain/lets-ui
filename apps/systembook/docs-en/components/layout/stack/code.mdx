## Centered Items

<ComponentEmbed component="Stack" variant="centered" />

## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `gap` | `string` | `16` |
| `align` | `string` | `stretch` |
| `justify` | `string` | `start` |

## Usage

### Web Component

```html
<lui-stack gap="md" align="stretch" justify="start">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</lui-stack>
```

### CSS class

```html
<div class="stack stack--gap-md">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
```
