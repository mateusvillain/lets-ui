## Best practices

<DosDonts variant="do" title="Elements in a column">
  Form fields, page blocks, card items or paragraphs.
</DosDonts>

<DosDonts variant="do" title="Even spacing">
  Instead of giving each element a margin, you set the space **once**, on the Stack. It is the most used layout primitive.
</DosDonts>

<DosDonts variant="dont" title="Elements side by side">
  Use [Inline](../inline/index.mdx) or [Flex](../flex/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Columns of a page grid">
  Use [Grid](../grid/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Switching between column and row depending on space">
  Use [Switcher](../switcher/index.mdx).
</DosDonts>

## Options

| Option | What it controls | Default |
| --- | --- | --- |
| `gap` | Space between items. | 16 |
| `align` | Horizontal alignment of the items. | Stretch |
| `justify` | Vertical distribution within the space. | Start |
