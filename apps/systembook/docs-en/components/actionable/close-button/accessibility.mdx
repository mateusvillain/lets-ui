## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves focus to the button. |
| `Enter` or `Space` | Closes or dismisses the element. |

Inside Modal and Drawer, `Esc` also closes the element, and focus returns to whatever opened it.

## Screen reader

- The button is announced with the name from the `label` property (default "Close"). Never leave `label` empty.
- The X icon is decorative and hidden from assistive technology.
- When disabled, the button is announced as unavailable.

## For designers

- Specify the `label` text for each use, in the product's language.
- When the Close Button sits inside another component, that component is responsible for giving it a meaningful `label` ("Close modal").
- The button is a `<button type="button">`, so it does not submit forms by mistake.
