## Scales

Each variant uses a type scale and a default element:

| Variant | Element | When to use |
| --- | --- | --- |
| `display` | `div` | Marketing highlights and heroes. It is not a semantic heading. |
| `title` | `h1` | Page title. One per page. |
| `subtitle` | `h2` | Subtitle, page introduction. |
| `headline` | `h3` | Section title. |
| `subheadline` | `h4` | Subsection title. |
| `block-title` | `h5` | Block or card title. |
| `overtitle` | `h6` | Label above the title, in all caps. |

## Alignment and truncation

The text can be aligned left (default), center, right or justified. With `line-clamp`, the heading is limited to a number of lines and ends with an ellipsis.
