## Best practices

<DosDonts variant="do" title="Menu items and tooltips">
  The action's keyboard shortcut, next to its name.
</DosDonts>

<DosDonts variant="do" title="Command lists and help screens">
  The available shortcuts, gathered in one place.
</DosDonts>

<DosDonts variant="dont" title="Teaching a whole flow">
  Write the step-by-step in text.
</DosDonts>

<DosDonts variant="dont" title="Keys the person does not have">
  On touch screens, for example, the shortcut cannot be used.
</DosDonts>

<DosDonts variant="dont" title="As a button">
  The Shortcut only displays, it does not trigger anything.
</DosDonts>

## Anatomy

![Shortcut anatomy: key, combination and separator](./anatomy.png)

1. **Key**: each key appears in its own piece.
2. **Combination**: several keys side by side, in the order they are pressed.
3. **Separator**: the "+" between the keys. It is decorative and hidden from screen readers.

## Types

| Type | When to use | Example |
| --- | --- | --- |
| **Single key** | Action keys. | `Enter`, `Esc`, `Tab` |
| **Combination** | Shortcuts with modifiers. | `Ctrl` + `K` |
