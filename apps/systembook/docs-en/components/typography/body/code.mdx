## Alignment

Use `align` with `left`, `center`, `right` or `justify`.

## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `label` | `string` | `''` |
| `variant` | `string` | `md` |
| `as` | `string` | `p` |
| `align` | `string` | `''` |
| `line-clamp` | `string` | `''` |
| `transform` | `string` | `''` |
| `color` | `string` | `body` |
| `italic` | `boolean` | `false` |
| `underline` | `boolean` | `false` |
| `bold` | `boolean` | `false` |

## Usage

### Web Component

```html
<lui-body variant="md" color="body" label="Content text."></lui-body>
```

### CSS class

```html
<p class="body--md">Text using the medium body type scale.</p>
```
