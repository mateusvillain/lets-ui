## Pacotes

O Let's UI publica três pacotes no npm. Use apenas o que precisar.

| Pacote | O que tem | Quando usar |
| --- | --- | --- |
| `@lets-ui/styles` | CSS compilado com os tokens, o reset, as foundations e as classes de todos os componentes. | Sempre. É a base de tudo, inclusive dos Web Components. |
| `@lets-ui/components` | Web Components feitos com [Lit](https://lit.dev/), a única dependência. Cada componente traz o CSS do próprio Shadow DOM, mas lê os tokens do `@lets-ui/styles`. | Componentes interativos: Modal, Dropdown Menu, Date Picker, campos de formulário. |
| `@lets-ui/tokens` | Só os tokens, em CSS custom properties, SCSS e JSON. | Quando você quer construir seus próprios estilos sobre os tokens, sem os componentes. |

## Começar rápido

O jeito mais rápido de testar é pela CDN, sem instalar nada. Copie o HTML abaixo para um arquivo e abra no navegador:

```html
<!doctype html>
<html lang="pt-BR" data-theme="light" data-brand="lets-ui">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <link
      rel="stylesheet"
      href="https://cdn.jsdelivr.net/npm/@lets-ui/styles@1/dist/letsui.min.css"
    />
    <script
      type="module"
      src="https://cdn.jsdelivr.net/npm/@lets-ui/components@1/+esm"
    ></script>
  </head>
  <body>
    <lui-card aria-label="Newsletter">
      <h2>Receba as novidades</h2>
      <lui-input label="E-mail" type="email" name="email" required></lui-input>
      <lui-button slot="actions" variant="primary">Assinar</lui-button>
    </lui-card>
  </body>
</html>
```

O `@1` fixa a versão maior: você recebe correções e novidades, mas não mudanças que quebram. Em produção, prefira instalar pelo npm e fixar a versão exata.

## Instalação

### Somente CSS

Para usar as classes CSS (`.btn`, `.card`, `.stack`...) sem JavaScript:

```bash
npm install @lets-ui/styles
```

Importe o CSS no ponto de entrada da aplicação:

```js
import '@lets-ui/styles';
```

Ou, sem bundler, com um `<link>`:

```html
<link rel="stylesheet" href="node_modules/@lets-ui/styles/dist/letsui.min.css" />
```

### Com Web Components

Instale **os dois pacotes**. Os componentes usam os tokens (`var(--lui-...)`) definidos no `@lets-ui/styles`. Sem ele, aparecem sem cor, fonte nem espaçamento.

```bash
npm install @lets-ui/styles @lets-ui/components
```

```js
import '@lets-ui/styles';

// Registra todos os componentes
import '@lets-ui/components';
```

Os componentes se registram como custom elements e ficam disponíveis no HTML:

```html
<lui-button variant="primary">Confirmar</lui-button>
<lui-button variant="secondary">Cancelar</lui-button>
```

Para usar React, Vue, Angular ou um framework com renderização no servidor, veja [Frameworks](./frameworks.mdx).

## Temas e marcas

O tema e a marca são escolhidos por atributos no elemento raiz, sem JavaScript.

### Modo claro e escuro

Aplique `data-theme` no `<html>`. Sem o atributo, vale `light`.

```html
<html data-theme="light">
```

```html
<html data-theme="dark">
```

Para trocar o tema com JavaScript:

```js
document.documentElement.setAttribute('data-theme', 'dark');
```

Para seguir a preferência do sistema operacional e lembrar a escolha da pessoa, veja [Themes](../../foundations/tokens/themes.mdx).

### Marcas

O atributo `data-brand` escolhe a marca: as cores `primary` e `secondary`, as fontes, os raios e a grade. A marca padrão, e hoje a única publicada, é `lets-ui`.

```html
<html data-theme="light" data-brand="lets-ui">
```

Ao trocar o `data-brand`, os tokens de marca (`--lui-brand-color-primary-*`, `--lui-brand-border-radius-*`...) mudam, e todos os componentes acompanham. Para criar uma marca nova, use o [Brand Studio](https://studio.lets-ui.com), o editor visual dos tokens de marca, e siga o passo a passo em [Themes](../../foundations/tokens/themes.mdx).

## Requisitos

| Requisito | Versão mínima |
| --- | --- |
| Navegadores | Versões atuais de Chrome, Edge, Firefox e Safari (CSS custom properties, Custom Elements v1 e Shadow DOM). |
| Node.js | 20+, para o bundler do seu projeto. Pela CDN, não é necessário. |
| Gerenciador | npm, pnpm ou yarn. |
