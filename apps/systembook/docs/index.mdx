# Let's UI

Let's UI is an open source, framework-agnostic design system, built on design tokens, CSS and native Web Components, for building consistent and accessible interfaces in any technology.

## Why Let's UI

- **One system, many brands**: light and dark themes and multiple brands come from the same tokens, switched with `data-theme` and `data-brand`, without JavaScript.
- **Any framework**: the Web Components are built with [Lit](https://lit.dev/) and work in React, Vue, Angular, Svelte or plain HTML.
- **Accessible from the start**: every component is designed for the keyboard, screen readers and contrast, aiming at WCAG 2.2 level AA.
- **CSS first**: layout primitives such as Stack, Inline and Sidebar work as plain CSS classes, with no JavaScript at all.

## Start in minutes

Install the styles and the components:

```bash
npm install @lets-ui/styles @lets-ui/components
```

Import both in the entry point of your application:

```js
import '@lets-ui/styles';
import '@lets-ui/components';
```

And use the components in the HTML:

```html
<lui-button variant="primary">Confirm</lui-button>
```

To try it with nothing to install, through the CDN, or to set up themes and brands, see [Installation](get-started/developers/installation.mdx). For React, Vue, Angular and server rendering, see [Frameworks](get-started/developers/frameworks.mdx).
