```scss
// No arquivo de componente
@use '../utilities/functions' as *;

.my-component {
  background-color: bg(surface, primary);
  color: text(body);
  border-radius: radius(sm);
  padding: fluid(16);
}
```

## Cores

| Função | Descrição | Parâmetros |
| --- | --- | --- |
| `bg($category, $variant)` | Cor de fundo semântica. | `$category`: `surface`, `container` · `$variant`: `primary`, `secondary`, `info`, `danger`, `success`, `caution`, `neutral`, `overlay` (só em `container`) |
| `text($variant)` | Cor de texto semântica. | `$variant`: `heading`, `body`, `caption`, `primary`, `inverse`, `error`, `link`, `link-visited` |
| `stroke($variant, $category?)` | Cor de borda semântica. | `$variant`: `primary`, `secondary`, `caution`, `danger`, `info`, `success`, `neutral` · `$category`: `default` (padrão), `subtle`, `hover`, `pressed` |
| `icon($variant)` | Cor de ícone semântica. | `$variant`: `primary`, `secondary`, `info`, `danger`, `success`, `caution`, `neutral`, `inverse` |
| `color($category, $scale)` | Cor primitiva da paleta. | `$category`: `primary`, `secondary`, `blue`, `gray`, `green`, `orange`, `red`, `violet` · `$scale`: `1` a `8` |
| `state($state, $bg?)` | Fundo do componente no estado: a tinta misturada ao fundo de repouso. | `$state`: `hover`, `pressed` |
| `tint($role)` | Tinta de estado de um componente preenchido, para o parâmetro `$tint` de `states()`, `state-layer()` e `state-base()`. São os extremos da escala neutra e se invertem com o tema. | `$role`: `foreground` (quase preto no claro, quase branco no escuro), `background` (o oposto) |
| `state-amount($state)` | Quanto da tinta misturar. | `$state`: `hover`, `pressed` |

### Exemplo de uso — cores

```scss
.alert--danger {
  background-color: bg(container, danger);
  border-color: stroke(danger);
  color: text(body);

  .alert__icon { color: icon(danger); }
}

.btn--primary {
  color: text(inverse);

  // A camada de estado é a mesma para toda variante e marca: o fundo de
  // repouso entra pelo mixin e as regras de estado misturam nele uma tinta.
  // Num componente preenchido, essa tinta é a cor oposta à do rótulo, para o
  // fundo se afastar do texto e o contraste subir no hover e no pressed.
  // `states()` já embute a camada; `$tint` troca a tinta.
  @include state-layer(bg(container, primary), tint(foreground));

  &:hover {
    background-color: state(hover);
    @include state-timing(hover);
  }

  &:active {
    background-color: state(pressed);
    @include state-timing(pressed);
  }
}
```

## Borda

| Função | Valor | Uso |
| --- | --- | --- |
| `radius($size)` | `none` | Sem arredondamento. |
| | `xs` | Tags, badges, chips. |
| | `sm` | Botões, inputs. |
| | `md` | Cards, modais. |
| | `lg` | Drawers, superfícies grandes. |
| | `xl` | Contêineres de destaque. |
| | `circle` | Avatares, ícones circulares. |
| `width($size)` | `0` | Sem borda. |
| | `1` | Borda padrão, 1px. |
| | `2` | Ênfase e foco, 2px. |

```scss
.card    { border-radius: radius(md); border-width: width(1); }
.avatar  { border-radius: radius(circle); }
.focused { border-width: width(2); }
```

## Espaçamento

| fn | desc | values |
| --- | --- | --- |
| fixed($size) | Espaçamento fixo em px | 0,8,16,24,32,40 |
| fluid($size) | Espaçamento fluido com clamp() | 2,4,8,12,16,20,24,32,40,48,56,64,72,80 |

```scss
.section { padding: fluid(40); }
.card    { padding: fluid(24); gap: fixed(16); }
```

<Callout variant="tip">
Use `fluid()` para espaçamentos de layout (margens, gaps entre blocos) e `fixed()` para espaçamentos internos de componentes que não devem mudar com o viewport.
</Callout>

## Tipografia

| fn | prop | values |
| --- | --- | --- |
| font($font) | font-family | heading,body,code |
| size($size) | font-size | 3xl,2xl,1xl,lg,md,sm,1xs,2xs,3xs |
| weight($weight) | font-weight | regular,medium,semibold,bold |
| line-height($lh) | line-height | heading,body |
| case($case) | text-transform | none,lowercase,uppercase |
| decoration($decoration) | text-decoration | none,underline,line-through |

```scss
.heading--title {
  font-family: font(heading);
  font-size: size(2xl);
  font-weight: weight(bold);
  line-height: line-height(heading);
}
```

<Callout variant="tip">
Para aplicar escalas tipográficas completas, prefira o mixin `font-scale($scale-name)`.
</Callout>

## Estados e elevação

| fn | desc | values |
| --- | --- | --- |
| focus-ring($variant) | Box-shadow de foco | primary,secondary,danger,success,neutral |
| elevation($layer) | Box-shadow de elevação | base,hovered,floating,overlay |
| opacity($category) | Opacidade semântica | disabled,hidden,visible |
| breakpoint($name) | Valor de breakpoint responsivo | 1xs (767px, teto),sm (768px),md (1024px),lg (1280px),1xl (1440px) |
| step-above($name) | Próximo step da escala de breakpoints | 1xs,sm,md,lg |
| grid($category, $name) | Valor da tabela do grid | columns,gap,margin,container |

```scss
.modal   { box-shadow: elevation(overlay); }
.tooltip { box-shadow: elevation(floating); }

.btn:focus-visible { box-shadow: focus-ring(primary); }
.btn:disabled      { opacity: opacity(disabled); }

@media (min-width: breakpoint(md)) {
  .sidebar { display: block; }
}
```

<Callout variant="tip">
  Para responsividade, prefira os mixins `media-up()` e `media-down()` em vez de chamar `breakpoint()` diretamente. Eles são complementos exatos um do outro (`media-down()` vale estritamente abaixo do piso do step), enquanto um `max-width` escrito à mão costuma deixar uma fresta em larguras fracionárias.
</Callout>

`breakpoint()` e `grid(columns, …)` são as duas únicas funções que devolvem um
valor literal em vez de um `var()`. Elas são lidas em tempo de compilação — por
um prelúdio de media query e pelo `@for` que gera as classes `.col-*` — e nenhum
dos dois consegue ler uma custom property. As demais categorias de `grid()`
(`gap`, `margin`, `container`) devolvem `var()` e continuam acompanhando
`data-brand` em runtime.
