## Quando usar

<DosDonts variant="do" title="Use quando">

Use o Radio Group quando a pessoa precisa escolher **uma única opção** entre duas a sete, e é importante ver todas lado a lado: método de pagamento, tamanho, frequência, plano.

</DosDonts>

## Quando não usar

<DosDonts variant="dont" title="Evite quando">

- **Escolher várias opções.** Use o [Checkbox](../checkbox/index.mdx).
- **Mais de sete opções.** Use o [Select](../select/index.mdx).
- **Ligar ou desligar.** Use o [Switch](../switch/index.mdx).
- **Escolha com efeito imediato e só duas opções**, como "Ativar notificações". Considere um Switch.

</DosDonts>

## Anatomia

1. **Título do grupo**: a pergunta que as opções respondem.
2. **Opções** (Radios): as escolhas possíveis.
3. **Hint** (opcional): texto de apoio abaixo das opções.
4. **Mensagem de erro**: substitui o hint quando falta escolha obrigatória.

## Variações

| Variação | Quando usar |
| --- | --- |
| **Padrão** | Escolha simples com título. |
| **Com hint** | A pessoa precisa de uma orientação adicional. |
| **Obrigatório** | A escolha precisa ser feita para continuar. |
| **Desabilitado** | A escolha não está disponível agora. |

Os tamanhos `lg` (padrão) e `md` seguem o [Input](../input/index.mdx).
