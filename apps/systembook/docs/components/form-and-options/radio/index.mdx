## Quando usar

<DosDonts variant="do" title="Use quando">

Use o Radio como parte de um [Radio Group](../radio-group/index.mdx), quando a pessoa precisa escolher **exatamente uma** opção entre duas a sete, e quer ver todas ao mesmo tempo.

</DosDonts>

<Callout variant="info">
  O Radio não vive sozinho. Para montar uma escolha completa, com título, dica e erro, use o [Radio Group](../radio-group/index.mdx), que organiza os Radios.
</Callout>

## Quando não usar

<DosDonts variant="dont" title="Evite quando">

- **Várias opções ao mesmo tempo.** Use o [Checkbox](../checkbox/index.mdx).
- **Ligar ou desligar.** Use o [Switch](../switch/index.mdx).
- **Mais de sete opções.** Use um [Select](../select/index.mdx).

</DosDonts>

## Anatomia

1. **Círculo**: mostra se a opção está escolhida.
2. **Label**: descreve a opção. Clicar nela também escolhe o Radio.

## Estados

| Estado | Descrição |
| --- | --- |
| **Não selecionado** | A opção não foi escolhida. |
| **Selecionado** | A opção está escolhida. Só uma por grupo. |
| **Foco** | Anel de foco ao navegar por teclado. |
| **Erro** | O grupo exige uma escolha e ela não foi feita. |
| **Desabilitado** | A opção não está disponível. |
