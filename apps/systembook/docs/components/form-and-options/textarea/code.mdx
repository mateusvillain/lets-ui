## With counter

Use the `maxlength` attribute to turn on the character counter. Ideal when there is an explicit input limit, such as a profile bio or a description field.

## Error

Use the error state to indicate that the field failed validation. `error-text` replaces the hint and is read by screen readers via `aria-describedby`.

<ComponentEmbed component="Textarea" variant="error" />

## Disabled

Use it when the content should be shown but not edited in the current context.

## Resize: None

Use `resize="none"` when the layout must not be disturbed by resizing — as in message boxes embedded in fixed forms.

## Form integration

`lui-textarea` is form-associated — its value is captured automatically by the parent form's `FormData` through the `name` attribute. The `form` attribute lets you associate it with a form by ID even when it sits outside the `<form>` element.

### Required

With `required`, the field blocks submission when it is empty, via `ElementInternals.setValidity()`.

## Properties

| Attribute | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | `''` | Text of the label above the field. |
| `value` | `string` | `''` | Current value. |
| `placeholder` | `string` | `''` | Example shown while the field is empty. Never replaces the label. |
| `size` | `string` | `lg` | `xl`, `lg`, `md` or `sm`. |
| `rows` | `number` | `4` | Visible height, in lines. |
| `resize` | `string` | `vertical` | `vertical`, `both` or `none`. |
| `maxlength` | `number` | `''` | Maximum number of characters. Turns on the counter. |
| `hint` | `string` | `''` | Help text below the field. Replaced by `error-text` when `error` is on. |
| `optional` | `boolean` | `false` | Adds the `optional-text` marker next to the label. |
| `optional-text` | `string` | `'(optional)'` | Marker shown when `optional` is on. |
| `disabled` | `boolean` | `false` | Disables the field and excludes it from submission. |
| `error` | `boolean` | `false` | Turns on the error state and shows `error-text`. |
| `error-text` | `string` | `'This field is required.'` | Message shown when `error` is on. |
| `aria-label` | `string` | `''` | Accessible name when there is no visible `label`. |

## Form attributes

| Attribute  | Type      | Default | Description                                                                   |
| ---------- | --------- | ------ | ----------------------------------------------------------------------------- |
| `name`     | `string`  | `''`   | Field name in the submitted data; required to appear in the `FormData`        |
| `form`     | `string`  | `''`   | ID of the associated `<form>`; lets you use the textarea outside the form element |
| `required` | `boolean` | `false`| Blocks submission when the field is empty; validates via `ElementInternals`   |

## Usage

### Web Component

```html
<lui-textarea
  label="Message"
  placeholder="Type..."
  size="lg"
  rows="4"
></lui-textarea>
```

### CSS class

```html
<div class="textarea-field textarea-field--lg">
  <div class="textarea-field__head">
    <label class="textarea-field__label">Message</label>
  </div>
  <div class="textarea-field__control">
    <textarea class="textarea-field__input" rows="4" placeholder="Type..."></textarea>
  </div>
</div>
```
