## Keyboard

The Shortcut only **displays** the shortcut: it does not receive focus and does not trigger anything. The shortcut needs to be implemented in the application.

## Screen reader

- Each key is marked as a keyboard key (`kbd`), and the combination forms a named group, such as "Ctrl + K", read all at once.
- Use `aria-label` to change the name that is read when symbols (such as `⌘`) are mispronounced.

## For designers

- Single-key shortcuts (without a modifier) can be **turned off or remapped** by people, per WCAG 2.1.4. Plan for this option.
- Show the shortcut next to the action in the text, so screen reader users can find it.
- Do not rely on shortcuts as the only way to perform an action.
