## Single key

Use it when the shortcut is a single key — such as action keys (`Enter`, `Esc`, `Tab`). Ideal for indicating confirmation or cancellation in forms and modals.

## Multiple keys

Use it when the shortcut requires a combination of keys pressed together. Pass the keys separated by commas in the `keys` attribute (e.g. `keys="Ctrl,K"`). The order should follow the platform convention: modifiers first (`Ctrl`, `Shift`, `Cmd`, `Alt`), then the main key.

## In context

Combine it with action lists or menus to document the shortcuts available in the interface. The component aligns naturally in `flex` layouts with `justify-content: space-between`.

## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `keys` | `string` | `''` |
| `aria-label` | `string` | `''` |

## Usage

### Web Component

```html
<lui-shortcut keys="⌘,K"></lui-shortcut>
```

### CSS class

```html
<span class="shortcut">
  <kbd class="shortcut__key">⌘</kbd>
  <span class="shortcut__sep">+</span>
  <kbd class="shortcut__key">K</kbd>
</span>
```
