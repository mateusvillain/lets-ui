## Alignment

Use `align` with `left`, `center`, `right` or `justify`.

## Line Clamp

The `line-clamp` attribute takes an integer and limits how much of the text is displayed.

## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `label` | `string` | `''` |
| `variant` | `string` | `title` |
| `as` | `string` | `''` |
| `align` | `string` | `''` |
| `line-clamp` | `string` | `''` |
| `transform` | `string` | `''` |
| `color` | `string` | `heading` |

## Usage

### Web Component

```html
<lui-heading variant="title" color="heading" label="Page title"></lui-heading>
```

### CSS class

```html
<h1 class="title text--color-heading">Page title</h1>
```
