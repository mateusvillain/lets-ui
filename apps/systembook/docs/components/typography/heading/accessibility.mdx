## Leitor de tela

- Leitores de tela permitem **navegar por títulos**, pulando de um para outro. Por isso a hierarquia precisa estar correta.
- Cada Heading renderiza o elemento semântico (`h1` a `h6`). Mude o elemento com `as` quando a hierarquia da página pedir.
- Um título vazio ou só decorativo atrapalha a navegação.

## Visual

- O texto deve ter contraste mínimo de 4,5:1 com o fundo. Textos grandes aceitam 3:1.
- Não use só a cor ou o tamanho para sugerir hierarquia: o elemento HTML também precisa refletir.

## Para designers

- Especifique o **nível** de cada título no design, além do estilo.
- Não crie "títulos falsos" com texto em negrito. Use o Heading.
- Ao truncar com `line-clamp`, garanta que o texto completo esteja acessível em outro lugar.
