## Leitor de tela

O Body renderiza um parágrafo (`p`), e o texto é lido na ordem do conteúdo.

## Visual

- O texto precisa de contraste mínimo de **4,5:1** com o fundo. Textos grandes aceitam 3:1.
- O texto deve poder ser **ampliado até 200%** sem perder conteúdo. Por isso os tamanhos usam unidades relativas.
- Não use só cor para destacar informação importante.

## Para designers

- Evite texto justificado e linhas muito longas.
- Use o tamanho `sm` com cuidado: textos pequenos são difíceis de ler para muita gente.
- Defina a **língua** do conteúdo na página, para o leitor de tela pronunciar corretamente.
