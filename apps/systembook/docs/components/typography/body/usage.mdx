## Legibilidade

- Mantenha linhas de **45 a 75 caracteres**. Linhas longas cansam e fazem a pessoa se perder ao voltar para o início da próxima.
- Use **parágrafos curtos**, de três a cinco linhas, e deixe espaço entre eles.
- **Alinhe à esquerda** (em idiomas da esquerda para a direita). O texto justificado cria espaços irregulares que dificultam a leitura, principalmente para quem tem dislexia.

<DosDonts variant="do" title="Alinhamento à esquerda e linhas curtas">
  Um bloco com largura confortável e margem à direita irregular. A leitura flui.
</DosDonts>

<DosDonts variant="dont" title="Texto justificado e largo">
  Uma coluna que ocupa a tela inteira e é justificada. Os espaços entre as palavras variam e cansam.
</DosDonts>

## Tamanhos

- `md` é o padrão para conteúdo.
- `lg` para o parágrafo de abertura de uma página.
- `sm` para legendas e notas. Evite usar `sm` para conteúdo importante.

## Estilo

- Use **negrito** e *itálico* com moderação, para ênfase real.
- Evite sublinhado fora de links: ele sugere clique.
- Não use caixa alta em textos longos.

## Escrita

- Prefira **frases curtas e linguagem simples**.
- Comece pela informação mais importante.
- Evite jargão e siglas sem explicação.

## Boas práticas

- Mantenha o mesmo tamanho para o mesmo tipo de conteúdo.
- Garanta contraste de pelo menos 4,5:1.
- Teste com o texto aumentado em 200%: o layout não pode quebrar.
