## Quando usar

<DosDonts variant="do" title="Use quando">

Use o Body para **todo texto que não é título**: parágrafos, descrições, legendas, notas e textos de apoio.

</DosDonts>

## Quando não usar

<DosDonts variant="dont" title="Evite quando">

- **Títulos.** Use o [Heading](../heading/index.mdx).
- **Atalhos de teclado.** Use o [Shortcut](../shortcut/index.mdx).
- **Rótulos de controles.** Eles já vêm nos componentes de formulário.

</DosDonts>

## Opções

O Body também aceita alinhamento (esquerda, centro, direita ou justificado), cor, estilo (como itálico) e decoração do texto.
