## Best practices

<DosDonts variant="do" title="Paragraphs and descriptions">
  All running text that is not a heading.
</DosDonts>

<DosDonts variant="do" title="Captions and notes">
  Text that supports the main content.
</DosDonts>

<DosDonts variant="dont" title="Headings">
  Use the [Heading](../heading/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Keyboard shortcuts">
  Use the [Shortcut](../shortcut/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Control labels">
  They already come with the form components.
</DosDonts>

## Sizes

| Size | Element | When to use |
| --- | --- | --- |
| `lg` | `p` | Introduction and highlighted text. |
| `md` (default) | `p` | General content. |
| `sm` | `p` | Captions, notes and helper text. |
