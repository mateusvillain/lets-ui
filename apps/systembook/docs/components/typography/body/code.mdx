## Alinhamento

Use `align` com `left`, `center`, `right` ou `justify`.

## Propriedades

| Atributo | Tipo | Padrão |
| --- | --- | --- |
| `label` | `string` | `''` |
| `variant` | `string` | `md` |
| `as` | `string` | `p` |
| `align` | `string` | `''` |
| `line-clamp` | `string` | `''` |
| `transform` | `string` | `''` |
| `color` | `string` | `body` |
| `italic` | `boolean` | `false` |
| `underline` | `boolean` | `false` |
| `bold` | `boolean` | `false` |

## Uso

### Web Component

```html
<lui-body variant="md" color="body" label="Texto de conteúdo."></lui-body>
```

### Classe CSS

```html
<p class="body--md">Texto com escala tipográfica body médio.</p>
```
