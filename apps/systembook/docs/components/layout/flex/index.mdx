## Quando usar

Use o Flex quando precisa de **controle fino** sobre direção, alinhamento, distribuição e crescimento dos itens: cabeçalhos com título à esquerda e ações à direita, barras de ferramentas, cartões com rodapé fixo.

Se [Stack](../stack/index.mdx) ou [Inline](../inline/index.mdx) resolvem, prefira-os: são mais simples e expressam melhor a intenção.

## Quando não usar

- **Colunas de uma grade de página.** Use [Grid](../grid/index.mdx).
- **Coluna simples com espaço uniforme.** Use [Stack](../stack/index.mdx).
- **Fileira simples que quebra de linha.** Use [Inline](../inline/index.mdx).

## Opções do contêiner

| Opção | O que controla |
| --- | --- |
| `direction` | Linha ou coluna, normal ou reversa. |
| `wrap` | Se os itens quebram de linha. |
| `gap` (`gap-x`, `gap-y`) | Espaço entre os itens. |
| `align` | Alinhamento no eixo transversal. |
| `justify` | Distribuição no eixo principal. |
| `inline` | Contêiner em linha, não em bloco. |

## Flex Item

O `lui-flex-item` controla um item individual: quanto cresce (`grow`), encolhe (`shrink`), sua base de tamanho (`basis`), o alinhamento próprio (`align`) e a ordem (`order`).
