## Common patterns

| Need | Combination |
| --- | --- |
| Title on the left and actions on the right | `justify="space-between"`, `align="center"` |
| Center an item on both axes | `justify="center"`, `align="center"` |
| An item that fills the remaining space | `grow="1"` on the item |
| Footer pushed to the end | Column with `grow="1"` on the body |

<DosDonts variant="do" title="Let an item grow">
  In a row with a search field and a button, give the field `grow`. It takes up the remaining space.
</DosDonts>

<DosDonts variant="dont" title="Fixed pixel widths">
  Setting fixed widths on items breaks on smaller screens. Use `basis` and `grow` to adapt.
</DosDonts>

## Responsiveness

Flex does not change on its own with the screen size. To switch between row and column depending on the space, use [Switcher](../switcher/index.mdx).

## Best practices

- Do not use margins for spacing. Use `gap`.
- Avoid nesting many Flex containers: if you need more than two levels, review the structure.
- Test with long and short text to see how the alignment responds.
