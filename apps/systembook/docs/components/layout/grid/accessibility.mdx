---
title: "Accessibility"
order: 3
---

O Grid é só layout e **não adiciona semântica**.

- **Ordem do código**: a ordem de leitura e de foco segue o código. Não reordene visualmente de modo que fique diferente da ordem do conteúdo.
- **Reflow**: no celular e com zoom de 200%, as colunas se reorganizam em menos colunas, sem rolagem horizontal.
- **Regiões**: use elementos semânticos (`header`, `main`, `nav`, `aside`) nas áreas da grade para criar pontos de referência para leitores de tela.
