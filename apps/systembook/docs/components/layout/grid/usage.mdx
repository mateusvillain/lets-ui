## Think in columns

Plan the layout in **columns**, not widths. A card can span 4 of 4 columns on mobile, 4 of 8 on tablet and 4 of 12 on desktop.

<DosDonts variant="do" title="Declare each breakpoint">
  Set how many columns the item spans on each screen, and check the jump from 8 to 12 columns at `lg`.
</DosDonts>

<DosDonts variant="dont" title="Forgetting the jump from 8 to 12">
  A `col-sm-4` is **half** the row at `sm`, but becomes **a third** at `lg` if it is not redeclared. Review each breakpoint.
</DosDonts>

## Distributing content

- Align main and secondary content to the same grid on every page.
- Use **empty columns** to add breathing room, instead of increasing one-off margins.
- For long text, limit the width to a comfortable reading range (about 8 of 12 columns).

## Nesting

Inside an item, use another Grid to subdivide. It takes the item's width and uses the same grid.

## Best practices

- Respect the grid's gaps and margins. Do not create extra margins outside it.
- Use Grid for the **page structure** and Stack, Inline and Flex inside each area.
- Test at every breakpoint, not just on desktop.
