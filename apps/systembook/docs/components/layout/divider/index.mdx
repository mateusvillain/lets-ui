## Quando usar

Use o Divider para **separar grupos de conteúdo** que pertencem a assuntos diferentes: seções de um menu, grupos de ações, trechos de um formulário, o "ou" entre duas opções de login.

## Quando não usar

- **Para criar espaço.** Use o espaçamento de [Stack](../stack/index.mdx) ou [Box](../box/index.mdx).
- **Separar cada item de uma lista.** Linhas demais poluem. Use espaço, ou os divisores da [Table](../../content/table/index.mdx).
- **Separar títulos de conteúdo.** A tipografia já cria a hierarquia.

## Variações

| Variação | Quando usar |
| --- | --- |
| **Horizontal** (padrão) | Separa blocos empilhados: menus, seções, formulários. |
| **Vertical** | Separa itens lado a lado, como em barras de ferramentas. |
| **Com texto** (`label`) | Separador com palavra, como "ou". |
