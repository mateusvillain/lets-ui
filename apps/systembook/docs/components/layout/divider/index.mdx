## Variações

| Variação | Quando usar |
| --- | --- |
| **Horizontal** (padrão) | Separa blocos empilhados: menus, seções, formulários. |
| **Vertical** | Separa itens lado a lado, como em barras de ferramentas. |
| **Com texto** (`label`) | Separador com palavra, como "ou". |
