## Use com moderação

O espaço em branco, o agrupamento e a tipografia separam o conteúdo melhor que linhas. Use o Divider quando **só o espaço não basta**.

<DosDonts variant="do" title="Separar grupos com significado diferente">
  Em um menu, um Divider antes da ação perigosa. A linha avisa que ela é diferente das demais.
</DosDonts>

<DosDonts variant="dont" title="Uma linha entre cada item">
  Linhas entre todos os itens de uma lista. A tela fica pesada, e a hierarquia desaparece.
</DosDonts>

## Divider com texto

Use o texto para marcar uma **escolha entre alternativas** ("ou") ou **nomear um grupo**. Mantenha a palavra curta.

## Vertical

Use na vertical para separar itens de uma barra de ações. Deixe o Divider da altura dos itens vizinhos.

## Boas práticas

- Mantenha o mesmo estilo de separador em todo o produto.
- Não use o Divider como única forma de indicar agrupamento: o espaçamento também precisa agrupar.
- Em menus, não coloque Dividers seguidos nem no início ou no fim.
