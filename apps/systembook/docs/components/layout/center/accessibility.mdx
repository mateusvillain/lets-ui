order: 3
---

Center is layout only and **adds no semantics**.

- **Text**: avoid centering long blocks of text. This mostly affects people with dyslexia or low vision.
- **Focus**: when centering content that appears in response to an action (such as an empty state), manage focus, as described in [Empty State](../../content/empty-state/accessibility.mdx).
