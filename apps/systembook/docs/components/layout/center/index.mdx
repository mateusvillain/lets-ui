## Boas práticas

<DosDonts variant="do" title="Estados de página inteira">
  Telas de estado vazio, carregamento e mensagens de página inteira.
</DosDonts>

<DosDonts variant="do" title="Seções de destaque">
  Um bloco centralizado dentro do espaço disponível.
</DosDonts>

<DosDonts variant="dont" title="Texto corrido">
  Centralizar parágrafos longos prejudica a leitura. Use alinhamento à esquerda.
</DosDonts>

<DosDonts variant="dont" title="Largura de página">
  Use [Container](../container/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Distribuir vários itens">
  Use [Flex](../flex/index.mdx).
</DosDonts>

## Eixos

| Eixo | Efeito |
| --- | --- |
| `both` (padrão) | Centraliza horizontal e verticalmente. |
| `horizontal` | Centraliza só na horizontal. |
| `vertical` | Centraliza só na vertical. |

<ComponentEmbed component="Center" variant="horizontal" />

Use `min-height` para dar altura ao espaço e `max-width` para limitar a largura do conteúdo.
