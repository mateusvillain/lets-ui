## Propriedades

| Atributo | Tipo | Padrão |
| --- | --- | --- |
| `threshold` | `string` | `320px` |
| `gap` | `string` | `16` |
| `limit` | `string` | `''` |

## Uso

### Web Component

```html
<lui-switcher threshold="320px" gap="md">
  <div>Panel A</div>
  <div>Panel B</div>
  <div>Panel C</div>
</lui-switcher>
```

### Classe CSS

```html
<div class="switcher switcher--gap-md">
  <div>Panel A</div>
  <div>Panel B</div>
  <div>Panel C</div>
</div>
```
