title: "Accessibility"
order: 3
---

O Switcher é só layout e **não adiciona semântica**.

- **Ordem de leitura**: a mesma do código, tanto em linha quanto empilhado.
- **Reflow**: ao ampliar o texto ou reduzir o espaço, os itens empilham, sem rolagem horizontal. É isso que o componente garante.
- **Conteúdo**: cada item precisa fazer sentido sozinho, porque a posição relativa entre eles muda conforme o espaço.
