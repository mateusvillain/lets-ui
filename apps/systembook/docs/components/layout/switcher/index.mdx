## Best practices

<DosDonts variant="do" title="Elements of equal weight">
  Feature cards, metrics, pricing plans or the steps of a process.
</DosDonts>

<DosDonts variant="do" title="Side by side or stacked">
  Items sit in a row when there is room and stack when there is not.
</DosDonts>

<DosDonts variant="do" title="Responding to the container">
  Switcher reacts to the **container's space**, not the screen size: it works in a narrow column or on a wide page.
</DosDonts>

<DosDonts variant="dont" title="A fixed side area and flexible content">
  Use [Sidebar](../sidebar/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Page structure in columns">
  Use [Grid](../grid/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Items that must always stay in a column">
  Use [Stack](../stack/index.mdx).
</DosDonts>

## Options

| Option | What it controls | Default |
| --- | --- | --- |
| `threshold` | Container width below which items stack. | 320px |
| `gap` | Space between items. | 16 |
| `limit` | Maximum number of items side by side. Above that, they stack. | No limit |
