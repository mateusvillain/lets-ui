The host element becomes an `inline-block` relative container, so no wrapper is needed.

## All Placements

Nine positions from the `placement` attribute: combinations of `top / middle / bottom` × `start / center / end`.

## With Offset

`offset-x` and `offset-y` shift the floating element from its anchor point. Accepts px values with or without the `px` unit (`"8"` or `"8px"`).

## Propriedades

| Atributo | Tipo | Padrão |
| --- | --- | --- |
| `placement` | `string` | `bottom-end` |
| `offset-x` | `string` | `0` |
| `offset-y` | `string` | `0` |
