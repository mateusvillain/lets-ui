---
title: "Accessibility"
order: 3
---

O Float só **posiciona**. O que importa para acessibilidade é o conteúdo que você coloca nele.

- **Indicadores**: um ponto de notificação ou um contador precisa ter **equivalente em texto**, para leitores de tela. Por exemplo, "3 mensagens novas" no nome do botão.
- **Decorativo**: se o elemento é só enfeite, esconda-o da tecnologia assistiva.
- **Sobreposição**: não cubra texto ou controles. Garanta que a área de toque do elemento de baixo continue acessível.
- **Contraste**: o elemento flutuante deve contrastar com o que está embaixo (3:1 para gráficos, 4,5:1 para texto).
