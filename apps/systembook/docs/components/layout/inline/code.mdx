## Propriedades

| Atributo | Tipo | Padrão |
| --- | --- | --- |
| `gap` | `string` | `8` |
| `gap-x` | `string` | `''` |
| `gap-y` | `string` | `''` |
| `align` | `string` | `center` |
| `justify` | `string` | `start` |
| `wrap` | `string` | `wrap` |

## Uso

### Web Component

```html
<lui-inline gap="sm" align="center" justify="start" wrap="wrap">
  <span>Design</span>
  <span>Engineering</span>
  <span>Product</span>
</lui-inline>
```

### Classe CSS

```html
<div class="inline inline--gap-sm">
  <span>Design</span>
  <span>Engineering</span>
  <span>Product</span>
</div>
```
