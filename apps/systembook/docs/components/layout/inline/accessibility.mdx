---
title: "Accessibility"
order: 3
---

O Inline é só layout e **não adiciona semântica**.

- **Ordem de leitura**: segue a ordem do código. Quando os itens quebram de linha, a ordem visual continua igual à do teclado.
- **Grupos de controles**: se o conjunto formar um grupo com significado (como uma barra de ferramentas), envolva-o em um elemento com papel e nome.
- **Zoom**: com texto ampliado, os itens quebram para a linha seguinte em vez de ficarem cortados.
