title: "Accessibility"
order: 3
---

Inline is layout only and **adds no semantics**.

- **Reading order**: follows the source order. When items wrap, the visual order stays the same as the keyboard order.
- **Control groups**: if the set forms a meaningful group (such as a toolbar), wrap it in an element with a role and a name.
- **Zoom**: with enlarged text, items wrap to the next line instead of being clipped.
