## Teclado

A Scroll Area recebe **foco** e pode ser rolada pelo teclado:

| Tecla | Ação |
| --- | --- |
| `Tab` | Move o foco para a região. |
| `Setas` | Rolam o conteúdo. |
| `Page Up` / `Page Down` | Rolam uma tela. |
| `Home` / `End` | Vão ao início e ao fim. |

Sem isso, quem não usa mouse não conseguiria ver o conteúdo que está fora da área visível (WCAG 2.1.1).

## Leitor de tela

- A região é anunciada como **região** com um nome. Defina um nome que descreva o conteúdo (por exemplo, "Lista de arquivos").
- Os indicadores visuais (fade e sombra) são decorativos.

## Para designers

- Não dependa só dos indicadores visuais: outras formas de chegar ao conteúdo ajudam.
- Evite esconder a barra de rolagem em regiões com conteúdo importante.
- Garanta que o foco da região tenha o anel de foco visível.
