---
title: "Accessibility"
order: 3
---

O Box é só uma superfície e **não adiciona semântica**. Use a opção `as` para renderizar o elemento certo (`section`, `aside`, `article`) quando ele representar uma região.

- **Contraste**: o texto sobre qualquer fundo do Box precisa de 4,5:1. Os tokens do sistema foram pensados para isso, mas teste combinações incomuns.
- **Estado**: não use só a cor de fundo (como `danger/surface`) para transmitir um estado. Inclua texto e, se possível, um ícone.
