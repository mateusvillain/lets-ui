## Centered Items

<ComponentEmbed component="Stack" variant="centered" />

## Propriedades

| Atributo | Tipo | Padrão |
| --- | --- | --- |
| `gap` | `string` | `16` |
| `align` | `string` | `stretch` |
| `justify` | `string` | `start` |

## Uso

### Web Component

```html
<lui-stack gap="md" align="stretch" justify="start">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</lui-stack>
```

### Classe CSS

```html
<div class="stack stack--gap-md">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
```
