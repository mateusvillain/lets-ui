## Quando usar

<DosDonts variant="do" title="Use quando">

Use o Stack para **organizar elementos em coluna** com um espaço uniforme: campos de um formulário, blocos de uma página, itens de um card, parágrafos.

É o primitivo de layout mais usado. Em vez de dar margem a cada elemento, você define o espaço **uma vez**, no Stack.

</DosDonts>

## Quando não usar

<DosDonts variant="dont" title="Evite quando">

- **Elementos lado a lado.** Use [Inline](../inline/index.mdx) ou [Flex](../flex/index.mdx).
- **Colunas de uma grade de página.** Use [Grid](../grid/index.mdx).
- **Alternar entre coluna e linha conforme o espaço.** Use [Switcher](../switcher/index.mdx).

</DosDonts>

## Opções

| Opção | O que controla | Padrão |
| --- | --- | --- |
| `gap` | Espaço entre os itens. | 16 |
| `align` | Alinhamento horizontal dos itens. | Esticar |
| `justify` | Distribuição vertical dentro do espaço. | Início |
