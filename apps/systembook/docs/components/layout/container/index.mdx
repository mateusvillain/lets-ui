## Boas práticas

<DosDonts variant="do" title="Largura legível">
  O texto não se estica por telas largas.
</DosDonts>

<DosDonts variant="do" title="Conteúdo centralizado na página">
  O Container limita a largura e centraliza o conteúdo.
</DosDonts>

<DosDonts variant="dont" title="Estruturar colunas">
  Use [Grid](../grid/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Uma superfície com fundo ou borda">
  Use [Box](../box/index.mdx) ou [Card](../../content/card/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Conteúdo que ocupa a tela toda">
  Para mapas e editores, use a variante de largura total.
</DosDonts>

## Tamanhos

| Tamanho | Quando usar |
| --- | --- |
| `sm` | Conteúdo de leitura e formulários estreitos. |
| `md` | Páginas de conteúdo intermediárias. |
| `lg` (padrão) | Páginas de conteúdo e painéis. |
| `full` | Largura total, sem limite. |

## Opções

O `padding` define o respiro lateral (padrão 32) e `center` controla a centralização.
