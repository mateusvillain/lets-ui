## Quando usar

<DosDonts variant="do" title="Use quando">

Use o Container para **controlar a largura legível** do conteúdo de uma página: o texto não se estica por telas largas, e o conteúdo fica centralizado.

</DosDonts>

## Quando não usar

<DosDonts variant="dont" title="Evite quando">

- **Estruturar colunas.** Use [Grid](../grid/index.mdx).
- **Uma superfície com fundo ou borda.** Use [Box](../box/index.mdx) ou [Card](../../content/card/index.mdx).
- **Conteúdo que deve ocupar a tela toda**, como mapas e editores. Use a variante de largura total.

</DosDonts>

## Tamanhos

| Tamanho | Quando usar |
| --- | --- |
| `sm` | Conteúdo de leitura e formulários estreitos. |
| `md` | Páginas de conteúdo intermediárias. |
| `lg` (padrão) | Páginas de conteúdo e painéis. |
| `full` | Largura total, sem limite. |

## Opções

O `padding` define o respiro lateral (padrão 32) e `center` controla a centralização.
