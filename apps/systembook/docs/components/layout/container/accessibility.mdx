title: "Accessibility"
order: 3
---

Container is layout only and **adds no semantics**. Use the `as` option to render the appropriate element (`main`, `section`, `article`) when it represents a region of the page.

- **Zoom and reflow**: the content stays readable with text enlarged to 200%, without horizontal scrolling.
- **Reading width**: short lines help people who have trouble reading, such as people with dyslexia.
