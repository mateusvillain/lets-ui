---
title: "Accessibility"
order: 3
---

O Container é só layout e **não adiciona semântica**. Use a opção `as` para renderizar o elemento adequado (`main`, `section`, `article`) quando ele representar uma região da página.

- **Zoom e reflow**: o conteúdo continua legível com texto ampliado em 200%, sem rolagem horizontal.
- **Largura de leitura**: linhas curtas ajudam quem tem dificuldade de leitura, como pessoas com dislexia.
