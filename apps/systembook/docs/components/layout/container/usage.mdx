## Reading width

For long text, choose a size that keeps **45 to 75 characters per line**. Longer lines make reading tiring.

## Padding

Side padding keeps the content away from the edges on small screens. Keep at least **16px** on mobile.

## When to use `full`

Use full width for elements that need room: dashboards with wide tables, editors and visualizations. Combine it with an inner Container when part of the content is text.

## Best practices

- Use one Container per section or per page, not one inside another without a reason.
- Keep the same size on pages of the same kind.
- Full-width backgrounds (colored bands) can sit outside the Container, with the content inside.
