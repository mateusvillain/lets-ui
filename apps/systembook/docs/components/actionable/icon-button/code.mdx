## Disabled

Use the disabled state when the action is not available in the current context. The button looks inactive and does not respond to interactions.

## All icons

Usage examples with SVG icons. The slot accepts any SVG or icon from any library.

## Toggle button

To turn an option on and off, use `aria-pressed="true"` or `"false"` and switch the value on each click. `aria-pressed="mixed"` has no style of its own and appears as not pressed.

<ComponentEmbed component="IconButton" variant="pressed" />

```html
<lui-icon-button aria-label="Show alerts" aria-pressed="true">
  <svg aria-hidden="true" ...>...</svg>
</lui-icon-button>
```

The attribute leaves `<lui-icon-button>` and moves to the inner `<button>`, so `lui-icon-button[aria-pressed="true"]` and `getAttribute('aria-pressed')` do not find it. Read the property (`button.ariaPressed`). To turn it off, use `aria-pressed="false"` or set the property to `null`: removing the attribute has no effect.

## Properties

| Attribute | Type | Default |
| --- | --- | --- |
| `size` | `string` | `md` |
| `disabled` | `boolean` | `false` |
| `aria-label` | `string` | `''` |
| `aria-pressed` | `string` | — |
| `aria-expanded` | `string` | — |
| `aria-haspopup` | `string` | — |

## Usage

### Web Component

```html
<lui-icon-button size="lg" aria-label="Close">
  <svg width="24" height="24" ...>...</svg>
</lui-icon-button>
```

### CSS class

```html
<button class="icon-button icon-button--lg" aria-label="Close">
  <svg width="24" height="24" ...>...</svg>
</button>
```
