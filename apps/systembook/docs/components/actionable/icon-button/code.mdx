## Disabled

Use o estado desabilitado quando a ação não está disponível no contexto atual. O botão fica visualmente inativo e não responde a interações.

## Todos os ícones

Exemplos de uso com ícones SVG. O slot aceita qualquer SVG ou ícone de qualquer biblioteca.

## Botão alternável

Para ligar e desligar uma opção, use `aria-pressed="true"` ou `"false"` e troque o valor a cada clique. `aria-pressed="mixed"` não tem estilo próprio e aparece como não pressionado.

<ComponentEmbed component="IconButton" variant="pressed" />

```html
<lui-icon-button aria-label="Mostrar alertas" aria-pressed="true">
  <svg aria-hidden="true" ...>...</svg>
</lui-icon-button>
```

O atributo sai do `<lui-icon-button>` e vai para o `<button>` interno, então `lui-icon-button[aria-pressed="true"]` e `getAttribute('aria-pressed')` não o encontram. Leia a propriedade (`button.ariaPressed`). Para desligar, use `aria-pressed="false"` ou a propriedade com `null`: remover o atributo não tem efeito.

## Propriedades

| Atributo | Tipo | Padrão |
| --- | --- | --- |
| `size` | `string` | `md` |
| `disabled` | `boolean` | `false` |
| `aria-label` | `string` | `''` |
| `aria-pressed` | `string` | — |
| `aria-expanded` | `string` | — |
| `aria-haspopup` | `string` | — |

## Uso

### Web Component

```html
<lui-icon-button size="lg" aria-label="Fechar">
  <svg width="24" height="24" ...>...</svg>
</lui-icon-button>
```

### Classe CSS

```html
<button class="icon-button icon-button--lg" aria-label="Fechar">
  <svg width="24" height="24" ...>...</svg>
</button>
```
