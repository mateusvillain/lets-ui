## As a link (`href`)

When the control **navigates or downloads** instead of running an action, it is semantically a link.
Passing `href` makes the component render `<a>` instead of `<button>`, keeping the same appearance
and the same styling attributes (`variant`, `size`, `block`).

This preserves the native behaviors that are lost when a button navigates programmatically:
opening in a new tab, right-click, middle-click, Ctrl/Cmd + click and the `download` attribute.

### New tab

With `target="_blank"`, `rel="noopener noreferrer"` is applied automatically.
A `rel` you provide is added to that protection, it does not replace it — `rel="nofollow"`
with `target="_blank"` results in `nofollow noopener noreferrer`.

### Disabled and loading

Links have no native `disabled`. With `disabled` or `loading`, `href` is omitted, so the element
does not navigate on click, middle-click or "open in new tab", and `aria-disabled="true"` plus
`role="link"` keep the announcement correct in screen readers.

The two states differ in focus: `disabled` gets `tabindex="-1"` and leaves the tab order,
like a native disabled button. `loading` is transient and gets `tabindex="0"`, keeping the
focus of whoever was already on the element when the operation started — without `href`, an anchor is not
focusable, not even programmatically.

Form attributes (`type`, `name`, `value`, `form`) do not apply when there is an `href`.

## Form integration

`type="submit"` and `type="reset"` work natively with any parent `<form>`.
Two submit buttons with different `name` and `value` let you identify which action was chosen
in the submitted data. The `form` attribute associates the button with a form by ID,
even when it sits outside the `<form>` element in the DOM.

## Autofocus

Use `autofocus` to move keyboard focus to the button automatically when its context is rendered.
The most common use case is the primary action of a dialog or modal: when it opens, focus is already on the right button,
so the user can confirm the action with Enter without navigating.

**Avoid using it on full pages.** Receiving focus automatically in the middle of the content disorients screen reader and
keyboard users, who expect to start navigating from the top. Reserve it for isolated, transient contexts,
such as modals, drawers and confirmation alerts.

## Attributes

| Attribute      | Type      | Default     | Description                                                                         |
| -------------- | --------- | ----------- | ----------------------------------------------------------------------------------- |
| `label`        | `string`  | `''`        | Text shown on the button                                                            |
| `variant`      | `string`  | `'primary'` | Visual style: `primary`, `secondary`, `neutral`, `danger`, `success`                |
| `size`         | `string`  | `'lg'`      | Size: `lg`, `md`                                                                    |
| `type`         | `string`  | `'button'`  | HTML type: `button`, `submit`, `reset`                                              |
| `name`         | `string`  | `''`        | Name submitted with the form when using `type="submit"`                             |
| `value`        | `string`  | `''`        | Value submitted with `name`; included only when this button triggers the submit     |
| `form`         | `string`  | `''`        | ID of the associated `<form>`; lets you use the button outside the form element     |
| `disabled`     | `boolean` | `false`     | Disables the button and prevents interactions                                       |
| `autofocus`    | `boolean` | `false`     | Moves focus to the button automatically when the context is rendered                |
| `block`        | `boolean` | `false`     | Makes the button full-width inside its container                                    |
| `loading`      | `boolean` | `false`     | Shows a spinner and blocks interactions; does not apply the disabled opacity        |
| `loading-text` | `string`  | `''`        | Alternative text shown while `loading` is active                                    |
| `href`         | `string`  | `''`        | When set, renders `<a>` instead of `<button>`                                       |
| `target`       | `string`  | `''`        | Navigation target; only applied together with `href`                                |
| `rel`          | `string`  | `''`        | Link relation; added to `noopener noreferrer` with `target="_blank"`                |
| `download`     | `string`  | —           | Downloads the resource instead of navigating; accepted without a value; only with `href` |
| `aria-label`   | `string`  | `''`        | Accessible label overriding the one derived from `label`                            |

## Usage

### Web Component

```html
<lui-button variant="primary" size="lg">Confirm</lui-button>
<lui-button variant="secondary" size="lg">Cancel</lui-button>
<lui-button variant="primary" size="lg" href="/cursos">View course</lui-button>
```

### CSS class

```html
<button class="btn btn--primary btn--lg">Confirm</button>
<button class="btn btn--secondary btn--lg">Cancel</button>
<a class="btn btn--primary btn--lg" href="/cursos">View course</a>
```
