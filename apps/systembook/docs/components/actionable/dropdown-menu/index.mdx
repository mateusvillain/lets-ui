## Boas práticas

<DosDonts variant="do" title="Várias ações relacionadas">
  Ações que ocupariam espaço demais se ficassem todas visíveis.
</DosDonts>

<DosDonts variant="do" title="Menu de conta">
  As opções da conta agrupadas atrás de um único gatilho.
</DosDonts>

<DosDonts variant="do" title="Mais opções de um item">
  O "Mais opções" de uma linha de tabela ou as ações de um documento.
</DosDonts>

O gatilho é livre: pode ser um [Button](../button/index.mdx), um [Icon Button](../icon-button/index.mdx) ou um link.

<DosDonts variant="dont" title="Duas ou menos ações">
  Mostre os botões diretamente.
</DosDonts>

<DosDonts variant="dont" title="Navegação principal do site">
  Use uma barra de navegação ou [Tabs](../../navigation/tabs/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Escolher um valor em um formulário">
  Use o [Select](../../form-and-options/select/index.mdx).
</DosDonts>

<DosDonts variant="dont" title="Conteúdo rico ou formulários">
  Menus são para ações curtas; para mais, use um Modal ou Drawer.
</DosDonts>

## Anatomia

1. **Gatilho**: o elemento que abre e fecha o menu.
2. **Painel**: a superfície flutuante com elevação.
3. **Item**: uma ação, com rótulo e, se quiser, atalho.
4. **Divisor**: separa grupos de ações.
5. **Submenu** (opcional): um segundo nível, indicado por uma seta.

## Elementos

| Elemento | Descrição |
| --- | --- |
| **Item** | Executa uma ação e fecha o menu. |
| **Item com atalho** | Mostra o atalho de teclado alinhado à direita. |
| **Item perigoso** | Ação destrutiva, destacada em vermelho. |
| **Item desabilitado** | Ação indisponível agora, mas que continua visível. |
| **Divisor** | Separa grupos com propósitos diferentes. |
| **Submenu** | Agrupa ações relacionadas em um segundo nível. |

## Estados do menu

Fechado e aberto. Ao abrir, o foco vai para o primeiro item disponível. Ao fechar com `Esc`, o foco volta para o gatilho.
