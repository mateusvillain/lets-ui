## Teclado

| Tecla | Ação |
| --- | --- |
| `Tab` | Entra na lista de abas, na aba ativa. Uma segunda vez vai para o painel. |
| `Seta para direita` | Ativa a próxima aba habilitada. |
| `Seta para esquerda` | Ativa a aba anterior habilitada. |
| `Home` | Ativa a primeira aba habilitada. |
| `End` | Ativa a última aba habilitada. |

Abas desabilitadas são puladas.

## Leitor de tela

- A lista é anunciada como `tablist`, cada aba como `tab` com o estado selecionado, e o conteúdo como `tabpanel`, ligado à sua aba.
- Só a aba ativa entra na ordem de tabulação. As setas movem entre as outras.
- O painel inativo fica escondido da tecnologia assistiva.

## Para designers

- Não indique a aba ativa só pela cor: use também o indicador (linha ou segmento).
- Garanta contraste de 3:1 no indicador e 4,5:1 no texto.
- Mantenha os rótulos curtos para que não quebrem em duas linhas.
