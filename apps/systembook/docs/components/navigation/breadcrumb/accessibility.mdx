## Teclado

| Tecla | Ação |
| --- | --- |
| `Tab` | Percorre os links do caminho, em ordem. |
| `Enter` | Abre o link em foco. |

## Leitor de tela

- O Breadcrumb é um landmark de navegação com um nome, como "Breadcrumb" ou "Trilha de navegação". Dê um nome no idioma do produto com `aria-label`.
- Os itens formam uma lista ordenada, e o leitor informa a quantidade de níveis.
- O item atual é marcado com `aria-current="page"`.

## Para designers

- O separador é decorativo. Não use só o separador para comunicar a relação entre níveis.
- Garanta contraste de pelo menos 4,5:1 nos links e área de toque confortável em telas pequenas.
