## Leitor de tela

- O texto alternativo (`alt`) é o que o leitor de tela anuncia. Descreva o que a imagem **comunica**.
- Imagens decorativas usam `alt` vazio e ficam fora da leitura.
- Com `caption`, a imagem e o texto formam uma figura com legenda, e o leitor reconhece a relação.

## Visual

- Não use só uma imagem para transmitir uma informação importante: repita no texto.
- Imagens com texto precisam de contraste e de uma alternativa em texto.
- A cor de fallback não deve prejudicar o contraste de textos que apareçam sobre a imagem.

## Para designers

- Escreva o `alt` junto com a imagem, durante o design.
- Considere quem tem conexão lenta: o espaço reservado e o fallback mantêm a página compreensível.
- Evite imagens que piscam ou se movem sem controle.
