## Keyboard

| Key | Action |
| --- | --- |
| `Tab` / `Shift+Tab` | Moves through the headers and the interactive content of open panels. |
| `Enter` or `Space` | Opens or closes the focused section. |
| `Down Arrow` | Focuses the next header (from the last, wraps to the first). |
| `Up Arrow` | Focuses the previous header (from the first, wraps to the last). |
| `Home` | Focuses the first header. |
| `End` | Focuses the last header. |

Disabled items are skipped.

## Screen reader

- Each header is a button inside a heading, so the screen reader lists the sections when navigating by headings.
- The button announces whether the section is **expanded or collapsed**.
- A closed panel stays out of the focus order and out of reading.
- The icon and the chevron are decorative.

## Motion

The height animation and the chevron rotation are turned off for people who prefer reduced motion.

## For designers

- Choose the **heading level** (`heading-level`) to match the page hierarchy, without skipping levels.
- Write titles that make sense in the page's list of headings.
- Do not put essential information only inside closed panels.
