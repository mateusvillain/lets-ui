## Teclado

A Tag **não é interativa**: não recebe foco nem responde ao teclado.

## Leitor de tela

- O texto da Tag é lido como parte do conteúdo ao redor. Por isso o rótulo deve fazer sentido junto ao item: "Pedido 1042, Pago".
- Não use só a cor para informar o status. O texto é essencial.

## Visual

- O texto tem contraste de pelo menos 4,5:1 com o fundo, em todas as variantes.
- Variantes diferentes não dependem só de tom: o texto indica o significado.

## Para designers

- Escolha rótulos que funcionem fora do contexto visual.
- Não use cores que pareçam iguais para pessoas com daltonismo para significados opostos, como `success` e `danger`, sem texto.
