## Screen reader

The Alert is announced automatically when it appears on the page, without requiring focus. The urgency level depends on the variant:

| Variant | Announcement | Effect |
| --- | --- | --- |
| `danger`, `caution` | **Assertive** | Interrupts the current reading. |
| `success`, `info` | **Polite** | Waits for the current reading to finish. |

- The title and the content are read together, as a single message.
- The icon is decorative.

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves focus to the close button and to actions inside the alert. |
| `Enter` or `Space` | Activates the focused button. |

## Visual

- Meaning never depends on color alone: the icon and the message text reinforce the variant.
- The text has a minimum contrast of 4.5:1 against the alert background.

## For designers

- Write the title and the content so they make sense **read aloud**.
- Set the close button text in the product's language (`close-label`).
- Use `danger` and `caution` only for what requires attention, because they interrupt reading.
