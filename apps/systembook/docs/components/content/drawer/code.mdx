## Sem ações

Omita `primary-button` e `secondary-button` quando o drawer for apenas informativo ou quando as ações forem parte do conteúdo interno (slot).

## close-on-backdrop: false

Por padrão o backdrop não fecha o drawer. Ative `close-on-backdrop` quando o fluxo permitir descarte acidental. Desative em formulários ou fluxos onde o usuário deve tomar uma decisão explícita.

## Propriedades

| Atributo | Tipo | Padrão |
| --- | --- | --- |
| `title` | `string` | `Drawer title` |
| `size` | `string` | `md` |
| `open` | `boolean` | `false` |
| `trigger-label` | `string` | `Open drawer` |
| `close-label` | `string` | `Close drawer` |
| `hide-trigger` | `boolean` | `false` |
| `close-on-backdrop` | `boolean` | `false` |

## Uso

### Web Component

```html
<lui-drawer title="Título" size="md" trigger-label="Open drawer" close-on-backdrop>
  <p>Conteúdo do drawer</p>
  <lui-button slot="actions" variant="secondary" label="Cancelar" data-drawer-close></lui-button>
  <lui-button slot="actions" label="Confirmar"></lui-button>
</lui-drawer>
```

### Fechar por uma ação

Marque com `data-drawer-close` o botão que só fecha o drawer, como um "Cancelar". Funciona no slot `actions` e no conteúdo, num elemento nativo ou num `lui-button`, e também quando o clique vem de algo dentro do elemento marcado.

- Fecha o `lui-drawer` mais próximo acima dele: dentro de um `lui-drawer` aninhado, fecha só esse.
- No slot `trigger`, o atributo é ignorado.
- Não fecha quando o clique passa por um controle com `aria-disabled="true"` (um `lui-button` em `loading`) ou quando um handler chama `event.preventDefault()`.
- Ações que fazem algo antes de fechar, como "Confirmar", chamam `closeDrawer()` no próprio handler.

O foco volta a quem abriu o drawer, como em qualquer outro jeito de fechar.

### Textos acessíveis

O botão de fechar usa `close-label` como `aria-label` (padrão: `"Close drawer"`). Troque-o para o idioma do projeto.

```html
<lui-drawer title="Título" close-label="Fechar drawer"></lui-drawer>
```

### Classe CSS

```html
<div class="drawer-backdrop is-open"></div>
<div class="drawer drawer--md is-open" role="dialog" aria-modal="true">
  <div class="drawer__header">
    <span class="drawer__title">Título</span>
    <button class="drawer__close" aria-label="Fechar">×</button>
  </div>
  <div class="drawer__body">Conteúdo do drawer</div>
  <div class="drawer__footer">
    <button class="btn btn--secondary btn--lg">Cancelar</button>
    <button class="btn btn--primary btn--lg">Confirmar</button>
  </div>
</div>
```
