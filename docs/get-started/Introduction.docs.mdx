## Instalação

Escolha a forma de instalação de acordo com o que o seu projeto precisa.

### Somente CSS

A maneira mais simples de usar o Let's UI. Instale o pacote de estilos — ele inclui o CSS compilado com todos os componentes, foundations e reset.

```bash
npm install @lets-ui/styles
```

Importe o CSS no ponto de entrada da sua aplicação:

```js
import '@lets-ui/styles';
```

Ou via `<link>` no HTML:

```html
<link rel="stylesheet" href="node_modules/@lets-ui/styles/dist/letsui.min.css" />
```

---

### Com Web Components

Para usar os componentes interativos (botões, inputs, modais, etc.), importe o pacote de componentes inteiro ou componentes individuais. Os estilos são injetados automaticamente — nenhum import de CSS adicional é necessário.

```bash
npm install @lets-ui/components
```

```js
// Registra todos os componentes
import '@lets-ui/components';

// Ou importe componentes individualmente
import '@lets-ui/components/button';
import '@lets-ui/components/modal';
```

Os componentes se registram automaticamente como custom elements e ficam disponíveis no HTML:

```html
<lui-button variant="primary">Confirmar</lui-button>
<lui-button variant="secondary">Cancelar</lui-button>
```

## Temas e marcas

O Let's UI suporta modo claro/escuro e múltiplas marcas via atributos HTML, sem JavaScript adicional.

### Modo claro / escuro

Aplique `data-theme` no elemento raiz. O valor padrão é `light`.

```html
<!-- Modo claro (padrão) -->
<html data-theme="light">

<!-- Modo escuro -->
<html data-theme="dark">
```

Para alternar o tema via JavaScript:

```js
document.documentElement.setAttribute('data-theme', 'dark');
```

### Multi-marca

O atributo `data-brand` define qual paleta de marca é usada. O tema padrão é `lets-ui`.

```html
<html data-theme="light" data-brand="lets-ui">
```

Tokens de marca como `--lui-brand-color-primary-*` e `--lui-brand-border-radius-*` são sobrescritos automaticamente ao trocar o `data-brand`.

## Installation

Choose the installation method that fits what your project needs.

### CSS only

The simplest way to use Let's UI. Install the styles package — it includes the compiled CSS with every component, foundations and reset.

```bash
npm install @lets-ui/styles
```

Import the CSS at your application's entry point:

```js
import '@lets-ui/styles';
```

Or through a `<link>` in the HTML:

```html
<link rel="stylesheet" href="node_modules/@lets-ui/styles/dist/letsui.min.css" />
```

---

### With Web Components

To use the interactive components (buttons, inputs, modals, etc.), import the whole components package or individual components. Styles are injected automatically — no additional CSS import is needed.

```bash
npm install @lets-ui/components
```

```js
// Registers every component
import '@lets-ui/components';

// Or import components individually
import '@lets-ui/components/button';
import '@lets-ui/components/modal';
```

Components register themselves automatically as custom elements and become available in the HTML:

```html
<lui-button variant="primary">Confirm</lui-button>
<lui-button variant="secondary">Cancel</lui-button>
```

## Themes and brands

Let's UI supports light/dark mode and multiple brands through HTML attributes, without extra JavaScript.

### Light / dark mode

Apply `data-theme` to the root element. The default value is `light`.

```html
<!-- Light mode (default) -->
<html data-theme="light">

<!-- Dark mode -->
<html data-theme="dark">
```

To switch the theme through JavaScript:

```js
document.documentElement.setAttribute('data-theme', 'dark');
```

### Multi-brand

The `data-brand` attribute defines which brand palette is used. The default theme is `lets-ui`.

```html
<html data-theme="light" data-brand="lets-ui">
```

Brand tokens such as `--lui-brand-color-primary-*` and `--lui-brand-border-radius-*` are overwritten automatically when `data-brand` changes.
