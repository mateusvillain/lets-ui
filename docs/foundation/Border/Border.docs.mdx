# Border

Tokens de borda do sistema de design. Controlam o arredondamento e a espessura das bordas — use as funções SCSS `radius($size)` e `width($size)` para acessá-los nos componentes.

---

## Border Radius

Escala de arredondamento, do reto ao completamente circular. Aplicado via `radius($size)`.

<div
  style={{
    display: 'flex',
    flexDirection: 'column',
    gap: '4px',
    marginBottom: '32px',
  }}
>
  {radii.map(({ name, token, value, px, use }) => (
    <div
      key={name}
      style={{
        display: 'grid',
        gridTemplateColumns: '64px 200px 1fr auto',
        alignItems: 'center',
        gap: '16px',

        background: 'var(--lui-color-neutral-background-surface)',
        border: '1px solid var(--lui-color-neutral-border-subtle)',
        borderRadius: '6px',
      }}
    >
      <div
        style={{
          width: '48px',
          height: '48px',
          background: 'var(--lui-color-primary-background-container)',
          borderRadius: `var(${token})`,

        }}
      />
      <div>
        <code style={{ display: 'block', fontSize: '12px' }}>{token}</code>

        style={{
