# Functions

Funções SCSS definidas em `packages/styles/src/utilities/_functions.scss`. Use-as nos componentes para acessar tokens de design de forma segura — cada função valida o argumento e lança um erro de compilação se o valor não existir no mapa de tokens.

```scss
// No arquivo de componente
@use '../utilities/functions' as *;

.my-component {
  background-color: bg(surface, primary);
  color: text(body);
  border-radius: radius(sm);
  padding: fluid(16);
}
```

</Lang>

# Functions

SCSS functions defined in `packages/styles/src/utilities/_functions.scss`. Use them in components to access design tokens safely — each function validates the argument and throws a compilation error if the value does not exist in the token map.

```scss
// In the component file

.my-component {
  background-color: bg(surface, primary);
  color: text(body);
  border-radius: radius(sm);
  padding: fluid(16);
}
```

## Cores

<ColorFnsList items={colorFns} />

### Exemplo de uso — cores

```scss
.alert--danger {
  background-color: bg(container, danger);
  border-color: stroke(danger);
  color: text(body);

  .alert__icon {
    color: icon(danger);
  }
}

.btn--primary {
  color: text(inverse);

  // A camada de estado é a mesma para toda variante e marca: o fundo de
  // repouso entra pelo mixin e as regras de estado misturam nele uma tinta.
  // Num componente preenchido, essa tinta é a cor oposta à do rótulo, para o
  // fundo se afastar do texto e o contraste subir no hover e no pressed.
  // `states()` já embute a camada; `$tint` troca a tinta.
  @include state-layer(bg(container, primary), tint(foreground));

  &:hover {
    background-color: state(hover);
    @include state-timing(hover);
  }

  &:active {
    background-color: state(pressed);
    @include state-timing(pressed);
  }
}
```

</Lang>

## Colors

<ColorFnsList items={colorFnsEn} />

### Usage example — colors

```scss
.alert--danger {
  background-color: bg(container, danger);
  border-color: stroke(danger);
  color: text(body);

  .alert__icon {
    color: icon(danger);
  }
}

.btn--primary {
  color: text(inverse);

  // The state layer is the same for every variant and brand: the resting
  // background comes in through the mixin and the state rules mix a tint into it.
  // In a filled component, that tint is the color opposite to the label, so the
  // background moves away from the text and contrast rises on hover and pressed.
  // `states()` already embeds the layer; `$tint` swaps the tint.
  @include state-layer(bg(container, primary), tint(foreground));

  &:hover {
    background-color: state(hover);
    @include state-timing(hover);
  }

  &:active {
    background-color: state(pressed);
    @include state-timing(pressed);
  }
}
```

> Use `fluid()` for layout spacing (margins, gaps between blocks) and `fixed()` for internal component spacing that should not change with the viewport.

</Lang>
